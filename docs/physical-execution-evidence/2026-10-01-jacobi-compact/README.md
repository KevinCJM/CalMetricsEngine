# Jacobi 连续前缀的紧凑工作区：详细设计

基线为2026-10-01的`6f02e6bb69d2d59a62781c357eda16f9604ae9eee2377af383b3b56b29c2bf6f`，保持全部有界Jacobi数学、i/j扫描、缩放、停止/错误、排序与符号。前轮补边原型虽有秒级收益，但工作区约翻倍；本轮以紧凑生存期表示减少该代价，并继续复用现有Eigen公开JacobiRotation。先隔离验证，条件成立后接入唯一正式模板、共享几何预算及完整引擎；不提交或推送。

## 表示与依赖证明

设M=N(N−1)/2。一个workspace的前N项始终是对角；其后M项保存每个无序非对角对唯一有效值。处理当前行i时：

- 未处理的上三角行k≥i，仍在原upper packed位置U(k,j)=kN−k(k+1)/2+(j−k−1)。这些位置从S(i)=iN−i(i+1)/2开始；不被已处理区覆盖。
- 已处理对在前S(i)项：j<i的完整lower行按j(j−1)/2开始；j≥i的长度i前缀按i(i−1)/2+(j−i)i开始。旋转i/j的k<i前缀是两个连续且不重叠的区段，成熟Eigen直接借用。
- 中间i<k<j和j之后的尾段继续使用upper packed，保持原独立元素的算式与顺序，避免稠密二次幂行距。
- 完成行i后，先把该upper行捕获到N项以内的临时带，再从大j向小j使用标准库memmove扩展lower前缀，每行末项接入捕获值。目标区终点正好S(i+1)，原lower数据已消费或搬运，后续upper从S(i+1)开始，二者不重叠。随后i增加。

每sweep结束后M项为标准lower packed；最大非对角检查仍按原i/j顺序读取逻辑(i,j)。只有需要下一sweep时，通过带访问标记的原地循环置换转回upper packed；对角和公开结果不参与置换。映射解码的平方根仅用于地址估计，再由整数行起点纠正，不能让浮点地址估计决定数学数据位置。逐一验证排列范围、互逆与canary。

临时带及置换bitset不同时存活，复用同一附加区。double容量为N+M+max(N+1,ceil(M/64))；1024阶比原packed仅多64KiB，不再多4MiB。容量溢出先于分配检查，正式Planner与prepare必须共享同一函数；原索引区在完整排序时仍需要。临时数组独占，不写只读输入或前次结果。

## 审计与取舍

如实累计初始H=N+M项复制、每行捕获/接入、prefix memmove和每次实际置换；初始归一化正常写入与物理搬运分类明确。每sweep前缀移动为N(N−1)(N−2)/6项，属于O(N³)额外复制，可能抵消SIMD收益；若无实质改进不接入。不得只报告64KiB而隐藏GB级累计搬运。成熟库调用数量实测，不把链接Eigen视为本次调用证明。

## 验证与正式接入要求

沿用原107个固定夹具，新增地址置换与生命周期边界；成功和失败缓冲逐位对照原静态库及真实引擎，保持浮点/离散语义。单CPU、独立结果、均衡轮换测512/768/1024，随后2048目标；不以小尺寸胜出替代大矩阵。完整heap/RSS与NJIT对照独立进程测量，准备/常驻缓存与运行峰值不能混淆。

正式采用必须只有一份Jacobi逻辑模板，旧布局承担非准入平台/形状的真实职责，不保留试验副本为生产备份。AST/DAG含义不改，prepare、Planner、root投影、子作用域、线程/进程、共享结果所有权和copy/库审计均需贯通；限定适用几何需有实际正负证据。全回归、原生/ASan/库关闭、源码/wheel/worker身份及185算子回放分别验证。全算子NJIT目标仍开放。

按D1–D8与X1–X10执行。Excel保持同一有界数学步骤和逻辑DAG，不展开内部地址搬运；普通执行不增加Excel工作。物理路径逐位等价成立后可复核同公式历史Excel快照，不表述为新的Excel桌面重算。若物理或数学验证失败，保留证据并继续定位，不改阈值或停止条件。


## 实测结论：拒绝接入

121个固定夹具、完整/仅值共242次成功和失败缓冲逐位对照，以及47组独立地址排列/范围/canary验证通过。六轮同核筛选结果如下，单位ms：

| N | 原C++仅值 / 紧凑候选 | 原C++完整 / 紧凑候选 | warmed NJIT仅值 / 完整 |
| --- | --- | --- | --- |
| 512 | 367.279 / 448.019 | 551.433 / 637.735 | 16.299 / 25.009 |
| 768 | 1241.471 / 1488.281 | 1915.431 / 2157.190 | 41.213 / 61.511 |
| 1024 | 3010.596 / 3600.595 | 4918.575 / 5366.624 | 103.236 / 152.049 |

紧凑前缀扩展和循环地址置换增加实质计算/复制，无法用其工作区节约抵消81–590ms退化。拒绝原因是完整重型时间收益不足，未因64KiB增加否决。该候选没有接入生产；不进一步测其堆/RSS，也不把其他构建的全回归当成候选通过。后续采用[双投影直写](../2026-10-01-jacobi-direct/README.md)，本负证据保留。
