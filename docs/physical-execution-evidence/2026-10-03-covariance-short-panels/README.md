# 短分块与 Eigen 误差界扫描隔离筛选

2026-10-03，macOS arm64；基线 `ecf16686c121d959600299583b9706e67bb337fc5cbaec42ebf09040ba627b2e`。
77 项生产/构建输入前后哈希一致。本轮只做独立 C ABI 筛选，**没有修改生产 C++、选择策略、公开协议或 Excel 公式**，没有提交推送。

## 设计与范围

沿用 [已有误差界推导](../2026-10-01-covariance-syrk/guarded-design.md)，将 C/负向 F 路径已有的逐块误差递推用于较短序列，尝试 32/64/128/256 行面板；原样保留 1e-12 容差、精确对角/符号/零、局部重放与 canonical 回退。候选仅取消这条试验路径的中心幅值 8 早退；源幅值 1e4、有限性、极小中心值及舍入模式等入口检查仍在。同一有界源域内中心值与范数运算保持正常有限范围；证书仍逐格决定结果，不依赖随机数据统计假设。

第二步用已经安装的 Eigen Array 处理独立的非对角块：将前一部分和转入固定 32×32 double 临时块，随后连续读写误差界；对角块保持已有逐格计算。每格的算术表达式和依赖不变，未调整证书或重放阈值。局部数组载荷为 8 KiB，不等于整个函数栈大小。这个小额成本不构成性能否决。

数学依据遵守 D1/D5/D8：均值、对角和最终消费者检查仍随本次输入重算，没有跨请求缓存；输入只读，输出由调用者独立分配；既有结果下三角暂存界，不增加第二个 D×D 数值数组。X1/X9/X10：纯物理候选不改变逻辑 DAG/公式，普通计算不触发 Excel；本轮没有 Excel 重算证据。

## 验证与测量

第一轮 36 类输入×5种配置通过；第二轮 39 类输入覆盖 C、倒序 C/F、补边负 F、正 F、尾块、大幅度/偏移/极小值/常量/负零及长相关序列。Eigen 与相同面板的逐格版本输出逐位、全部审计计数一致；相对当前实现保持原容差、精确对角/符号/零及输入不变。所有 6 个计时样本先通过当前实现与热态 NJIT 原 1e-12 对照。不能据此关闭此前乘 16384 样本的独立 NJIT 资格失败。

两个计时批次分开保留。下表只来自第二批：同输入、单 CPU、5 轮循环换序、每种实现各占据一次顺序位置；包含 C ABI 内的校验、输出分配、必要面板、库调用和回退。NJIT 已编译，返回相同的单个完整对称协方差矩阵。C++ 候选还执行双根适用的相关矩阵误差准入，但没有构造第二个相关矩阵结果。**没有普通 Scheduler、AST/Planner、worker 或异构多输出封装，因此不是完整请求验收。**

短面板可减少 scaled 的大额回退时间，但强制用于普通数据会引入明显退化；256 行仍有不确定单元过多而整块回退的情况。候选尚未采用，后续须针对真正的幅度拒绝选择短面板，保留普通路径，并继续降低与 NJIT 的剩余差距。不能通过跨样本平均隐藏这些问题。

本轮只记录 `scratch_bytes` 等原生计数，**未做新鲜进程 heap/RSS 内存验收、sanitizer、完整 Python 回归或实际 wheel 对照**。面板减少与额外 8 KiB 局部块是存储设计事实，不是全请求内存峰值结论。生产接入前须完成这些检查及错误、所有权、线程/进程、预算路径验收。几 KB/几毫秒差异按 AGENTS/D8 记录为诊断，不单独否决；秒级回退和完整负载内存差距仍是优化重点。
