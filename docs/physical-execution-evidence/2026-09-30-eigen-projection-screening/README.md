# Jacobi 输出整理与独立特征值投影：设计及验收

设计和原型筛选开始于 2026-09-30，正式接入、回归与最终独立时间复验于 2026-10-01 完成。基线是非负 MatMul 构建 `4df196c9a2c64c984bb940754de488099b9ab2ce1c51253b5d3a8dfdce476f1e`，本轮构建为 `33c2f2b95e374d396dc283c78d2ca5a43ad51a7a97995c3534ffdbae61ff7d39`。前一轮有正式接入/回归，属于进展；本轮进一步减少大矩阵死计算与中间存储。整体全算子中大型时间与内存明显领先 NJIT 的目标仍开放，未提交或推送。以下先保留筛选时的设计，再记录实际采用与证据。

数学纪律要求保留有界cyclic Jacobi的缩放、每个i/j旋转、原乘加顺序、tolerance/max_sweeps、NON_CONVERGENCE、升序稳定排序与最大绝对分量首位置取正。不能将默认参数的普通随机样本收敛，当成换用LAPACK分治/QR分解的授权。

候选一只改变已计算完的有限eigenpair记录排序：用标准库iota/sort生成总序索引，值相等时按原行号排序；循环置换通过标准库copy_n复用已经死去的数值工作区作一个行缓冲。数值计算和符号归一化结束后才整理；保持每个double原始位模式，避免原稳定插入排序对完整N+1行进行O(N³)交换。增加N个size_t索引；若采用须明确Planner/Workspace容量与独立结果/失败前缀，不能因为只有几KB就省略预算。

候选二依据实际依赖剪去死输出：仅当唯一consumer为eigenvalues、eigenvectors/record没有外部消费时，旋转参数和停止只依赖对称工作矩阵，不依赖特征向量。复用原Jacobi数学和Eigen MatrixRotation处理矩阵，只省去向量初始化/旋转/符号归一化及完整record。仍沿原i/j计算和检查，最后得到逐位相同的升序值。原型输出N个double；生产采用前必须将唯一consumer/结果根、子作用域、isolate/观察器边界、arena/Planner、四lane及独立结果贯通，不能仅修改最终NumPy切片。

先覆盖C/F/补边/反向stride、空/小/边界尺寸、重根/有符号零/极值/非有限/非对称、预算耗尽、默认与显式参数；候选一全record成功及失败前缀逐位比较，候选二成功values逐位及错误码比较，检查readonly输入与输出哨兵。随后相同CPU、预分配完整输出、均衡轮换大矩阵计时；只有实际收益支持采用后，才做正式代码/全回归、完整旧/新/warm-NJIT和fresh堆/RSS验收。

本轮不修改公开算子、金融语义、数学/逻辑 AST/DAG、Excel 公式或 Excel 预算；物理执行与工作区预算按实际采用更新。筛选不能作为普通用户入口成绩；未验证項不能记为通过。若没有重大收益，保留全部正负证据并转向其他重型路径。

## 实际采用与自审核

- 复用同一个 `symmetric_jacobi<Packed,ValuesOnly>` 模板；独立值路径省去 V 初始化/旋转/符号整理，矩阵计算、缩放、停止、有限检查和标量稳定插入排序不变。N≥128 的完整记录改用标准库 iota/sort 与 copy_n 循环置换；总序以原行号打破相同值的平局，保持原稳定排序，缩放矩阵在提取结束后充当行缓冲。
- `Program::finalize` 仅标记类型化非隔离图中、相邻且唯一消费的分解→值投影。公开直接视图、共享向量和有观察器执行保持原逻辑节点。健康子作用域可以使用物理裁剪；继承错误隔离/故障捕获时不裁剪。邻接约束保持数值错误与后续独立节点的执行先后；严格路径原异常直接抛出，隔离路径不延迟生产者。
- Compiler 保留逻辑 borrowed 生命周期，另为值投影提供可选物理目的槽；未融合视图不申请该槽。缩放矩阵必须在任何投影写入之前复制完，因此 arena 中的派生输入可复用死存储；最终 N 元素直接写本次独立根。C/F/补边/反向输入不转换；向量目的地连续。空输入仍由 Planner 选择 single，不能把零工作强行分配到进程。
- 完整分解的 N 个 size_t 进入 prepare/Workspace；值路径只使用原矩阵 scratch。Planner 仍是保守容量估算，并为继承隔离的子图禁用 arena 延迟消除，容纳完整记录。没有增加 opcode、nominal 类型、审计字段或 IPC；协议仍为 15。旧序列化图中未分配投影槽的节点继续执行原视图路径。
- 输入或参数变化每次重算，不按地址缓存特征分解；独立快照、跨行结果和线程/进程/shared 所有权由原原生结果协议承接。没有新增私有线程池、Python 数学计算或算法版本，也没有将 Jacobi 静默替换为 LAPACK。

## 完整负载测量方法

[benchmark.py](benchmark.py)运行旧/新独立安装包与预热的同核数 NJIT，输入 readonly，完整 Scheduler 普通/独立 prepared 快照均保留上一次结果。六轮按三后端循环换序，记录 wall/CPU 原样本、输出 hash、实际线程库与构建。仅值使用 NJIT `np.linalg.eigvalsh`，值与向量使用 `eigh` 加原符号归一化；它们是更强的成熟库性能参考，并不实现有界 Jacobi 的 sweep/错误契约。不得把数学算法不同这一事实隐去，也不据此删除较快参考。

初次 `production-timing/` 与测试、堆采样并发，保留为诊断，不作为采用成绩。`production-timing-final/` 在本轮测试/堆采样结束后单独重跑，才作为最终时间证据。内存的 18 个 fresh child 分开记录完整 setup/cold/warm 活跃 malloc 峰和 RSS；堆探针必须启用且观察到最终输出，峰值包含常驻工作区及两份保留结果，不能另把几个阶段峰值相加。输入在 epoch 前已存在，Python arena/栈/mmap 不由该 malloc 探针完整覆盖，RSS 作为独立补充。原始 [内存记录](production-memory/memory.json)与[增量摘要](memory-summary.json)保留所有正负差异。

1024 阶仅值请求：cold/warm 堆分别从 **12,613,021/12,621,736 B** 降至 **4,216,221/4,224,936 B**，各少 **8,396,800 B**；NJIT 为 **8,675,608/8,684,024 B**。完整值/向量 1024 和 2048 请求分别增加 **8,192/16,384 B** 的索引，按当前政策不单独否决。它们较 NJIT 的堆峰分别少约 **5.27/17.25 MiB**，仅是实测负载申请堆。仅值新包 RSS delta 约 **4.31 MiB**、旧包约 **0.39 MiB**；保留该页级观察，不能据 malloc 改善宣称 RSS 一定改善、整引擎内存全面领先或缓存成本不存在。

## 最终时间结果与采用结论

| 完整请求（CPU=1；六轮中位） | 旧 C++ ms | 新 C++ ms | warmed NJIT ms |
| --- | ---: | ---: | ---: |
| values_512_c | 553.439042 | 365.318125 | 16.510917 |
| values_1024_c | 4917.051979 | 2951.769937 | 104.102958 |
| values_1024_f | 4905.507042 | 2949.102729 | 99.669687 |
| full_1024_c | 4907.881105 | 4839.516521 | 163.888520 |
| values_1024_prepared | 4906.050271 | 2947.659521 | 104.881687 |
| descending_full_2048 | 1733.478020 | 70.374062 | 1790.788188 |
| small_values_16 | 0.035416 | 0.033417 | 0.012042 |

7 组最终输出的旧/新值逐位一致，完整向量另核对相同 hash；所有值也通过原 `rtol=atol=1e-9` 的 NJIT 数值对照，不放宽容差。1024 阶只取值普通 C/F 与 prepared 均节省约 **1.96 秒（约 40%）**，完整稠密分解仅约 68 ms 改善。2048 阶降序对角矩阵保留全值/向量时，标准库置换消除行插入的大量移动，**1733.478→70.374 ms**，约 **24.6 倍**，与该负载 NJIT **1790.788 ms** 相比约 **25.4 倍**；新 C++ 该负载 cold/warm 申请堆较 NJIT 少约 **17.25 MiB**。这一特殊排序负载不能代表随机稠密分解。

16 阶小请求新包约 **0.0334 ms**、NJIT约 **0.0120 ms**，绝对差约 **0.0214 ms**；保留差值，不按比例单独否决大负载优化。完整分解增加 8/16 KiB 索引同样不是阻断项。采用理由是删去死输出带来的秒级收益和约 8 MiB 中间存储节约，以及排序重负载的显著收益；并非为几 KB 或几毫秒持续微调。

**未关闭项：**普通 512/1024 阶稠密矩阵的新 C++ 仍约为 NJIT 成熟 LAPACK 的 **22–30 倍耗时**。有界 Jacobi 的矩阵旋转/访存仍是大头，完整向量路径尤其明显。按当前版本数学契约不能静默换成 QR/分治 LAPACK；也不能把特殊对角矩阵胜出、申请堆下降或小请求可接受扩大成全算子时间与内存全面领先。通用布局/重型算法和混合符号 MatMul 的实质差距继续开放。仅本机、这些形状/入口/输入和实际构建验证；本轮未提交、推送或修改 FundInvestmentResearchPlatform。
