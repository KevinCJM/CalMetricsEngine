## 详细设计与自审核

[集成设计](integration-design.md)记录先设计、原型筛选及三次按失败证据收窄准入。四行×八列由已有Eigen3.4 Array惰性表达式完成，每个结果仍从+0按原k顺序计算；只在方阵、精确C右矩阵、整8列及原平台/ISA条件成立时进入。显式ISA、F路径和其他形状保留支持。没有新增逻辑算子、金融约束、DAG/Planner协议、IPC字段或Python数学路径。

重复行复用依赖A行stride恰为0，而非近似判断数据相同；先执行一行的原计算，再 `std::copy_n` 到本次独立输出。支持C/F及padding、非整8列矩形；不缓存绑定值，prepared重新读取输入。`isa=matmul-repeated-rows` 与Eigen标识区分，真实复制计入 `algorithm_copy_bytes`。

[最终代码与工具审核](final-code-tool-review.md)覆盖IEEE、消去/FMA边界、真实worker内布局、布尔/除零错误隔离、CSE、输入只读、独立结果、prepared刷新及实际准入。既有契约夹具保持 `rtol=2e-12, atol=2e-14`；正式NJIT对照继续使用既有 `rtol=atol=1e-11`。保序逐位对照是实现证据，不把全域逐位相等新增为算子契约。

[实际对象审核](production-static-review.md)区分数学循环、分派与系统callee栈；没有新增数值堆工作区、FMA或浮点寄存器栈溢出。不能以局部frame、零workspace推断系统栈或RSS为零。没有增加线程池或全局BLAS线程设置。

## 为什么没有直接接入完整BLAS

[库准入审核](library-admission-review.md)包含当前容差和非有限输入的失败样本。Apple新LP64 BLAS在132个支持样本中7个不满足原契约，其中6个改变非有限分类；vDSP同样存在失败。1024阶预分配输出实验仍有额外约6.3MB库分配。没有修改容差、掩盖NaN/Inf或忽略额外内存后宣称替换通过。这不否定未来有充分证据的受控准入。

[借用输出工作区的后续设计](output-workspace-gemm-design.md)仅为候选分析，尚未实现或验收。NJIT真实库调用链与NumPy自身库记录区分，不据后者推测AMX硬件已经启用。

## 内存与所有权

51/114用例、306个独立child；冷/热活跃堆峰值新−旧范围分别为0至0 B、0至0 B。原始[51项内存](memory.json)含306个独立子进程，heap/RSS分别测量，不是全部114项内存验收。setup、首次数学和库初始化在cold窗口；暖态保留两份独立结果。连续heap峰已经包含setup存活，不能重复加总；输入hash此前可能分配后释放bytes，不能声称空分配器启动。

[安装路径归因](install-path-memory-attribution.md)保留16d2原+8B存活/+72B累计分配；6个child在相同二进制和等长真实目录下差异归零，当前完整验收继续等长路径。该归因没有逐个分配栈，不能越界宣称完整RSS已定位。

RSS总峰差中位+98,304 B，范围-51,937,280至+26,689,536 B，27/51为正；请求增量差中位-32,768 B，范围-50,511,872至+25,083,904 B，19/51为正。堆计数不能替代RSS或完整内存不增的证据。每个RSS组合只有一次进程测量，采样可能漏短峰值；不将正差一概当噪声。广播行真实复制 `(M−1)*N*8`，输出独立；direct无采集的审计字段不伪造为零。
