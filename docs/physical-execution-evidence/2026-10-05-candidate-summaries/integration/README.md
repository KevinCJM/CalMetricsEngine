## 实际变化与质量

编译时证明私有 `matmul` 的全部消费者为行统计及有限的浮点输出闭包；执行时
共享均值和中心化 Gram，复用 Accelerate 的 DSYRK/GEMM/GEMV/DOT，有界分块，
不物化 N×T。数值准入不确定时有界调用现有 canonical matmul/统计次序；
错误仍在原逻辑消费者检查。Planner、Scratch、进程重建及审计贯通。
比较/离散消费者、公开明细、observer、isolate、子作用域等保持既有执行。

同源完整 Python **13,074通过，无skip**，包含新增63项；普通原生 **9/9**。
实际 ASan/UBSan 扩展相关 **254项**、原生 **9/9**；三库OFF相关 **254项**、
原生 **9/9**。实际目录正式重建包另验 **254项及原生9/9**；接口16份、测试128份
源与完整回归冻结源一致，数值/配置89份与普通/SAN/OFF源一致。
另补充24例实际窗口小于规划上界的 C/F、空/短窗口及四运输所有权检查。
没有宣称全量SAN/OFF、LeakSanitizer、跨平台或新Microsoft Excel验收。

测试覆盖独立长精度公式、非负性、NaN/Inf/溢出、动态ddof、错误优先顺序、
多个producer/消费者、取消恢复、输入不变、live prepared、两区间两代、预算与
容量收缩。Excel诊断observer取得真实逻辑中间值，状态仍为 `NOT_RECALCULATED`；
公开公式、目录190项、预算与普通请求不触发导出的契约未改变。

## 公平完整链与正式数据

这是**给定候选的均值/标准差完整数学任务**，使用代表性合成数据；并非完整
随机探索或平台服务。每次计时包括独立只读输入准备、普通Scheduler绑定/规划/
图执行及独立结果返回，两代保留、CPU1、NJIT预热、编译排除。fixture/图构造在
重复计时外，在峰值内存epoch内。既有流式NJIT只使用一个历史轨迹，不以dense
NJIT作劣势基线；另保留相同共享统计量算法的NJIT成熟库对照。
