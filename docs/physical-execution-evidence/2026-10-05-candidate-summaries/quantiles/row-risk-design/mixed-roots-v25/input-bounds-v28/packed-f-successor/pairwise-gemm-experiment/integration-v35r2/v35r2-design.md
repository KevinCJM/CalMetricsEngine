# V35：已测 Accelerate 分块策略进入真实引擎

基线为已验 V33（数学源92份，身份1964a703）。前序同核完整筛选中4096高幅值，普通V33约6.34秒、分块Accelerate独立C ABI约1.09秒、强NJIT约0.70秒；BLIS同计划3.55秒，已排除本机该替换。此设计旨在使秒级收益进入真实普通引擎，不缩小全部主要负载领先NJIT的整体目标。

## 数学、依赖与准入

沿用既有independent_matmul_root证明：typed float64独立矩阵根或唯一transpose视图，没有比较/状态/其他消费者、隔离或作用域。旧非负/符号一致和已准入一次DGEMM路径保留原行为；只有旧混合符号误差界不能准入时评估分块。小任务、异常IEEE域和未资格平台继续当前canonical原生路径，没有新算子或Python回退。

原型原152控制及五组完整筛选不删。仍使用RN binary64/FMA标准GEMM模型，0.000049数学/回放预算、正一/二范数向上界、gamma(2b+2+q)顺序归并或gamma(2b+2+ceilLog2(q))平衡归约。不宣称供应商实现的形式化证书。近零/符号歧义用原序dot回放，证书不满足时整根canonical回放，完全覆盖先前部分结果；不得公布半结果或把晚拒绝说成未写过内存。

几何资格只扩展原独立根的512–8192输出维、256–8192收缩轴，以及有界正leading C/F视图。输入边界在本次请求重新读取，没有数值缓存。原型bound扫描不再重复：现有根全域检查得到的maxabs参数传入分块计划，符号/零边界保持原规则；既有sign数组按新有界维扩大。

## 分配、布局与所有权

结果借用本次独立typed根的可写地址，保持真实C/F strides；不写输入或旧结果。第一次部分积直接写根，后续Eigen明确归并；平衡策略只复制最终tile一次。纯复制按algorithm_copy_bytes计，算术读写量另作诊断，不称零访存。

Eigen范数的相反物理轴统计使用调用方Workspace的两个Map；准入阶段用最多2*8192+8 doubles的独立临时缓冲，确保拒绝时不改变调用方工作区。临时缓冲在扩容/分块之前释放，归并工作区峰上界仍为320K+72 doubles；没有私有池或保留数据内容。旧工作区与临时范数缓冲可同时存活，这部分峰值由既有工作区加库预留的保守准入涵盖，并以fresh堆/RSS复核。增长/几何切换先释放过大容量再增长，不出现旧新双份逃逸。

Planner通过既有matrix_workspace_doubles同时预留显式分块上界和原系统库workspace保守估计；实际分配仍懒执行。保留公开native_library_workspace_reserve_bytes为库估计本身，明确它不是供应商已证明的malloc上界。实际fresh堆/RSS覆盖库内部packing、输入准备和两代独立结果，不用显式scratch计数代替总峰值。

## 资源、错误与审计

调用在Scheduler已准入的线程内，以现有BLAS线程局部单线程控制执行；正常、晚拒绝、超时、取消和异常都恢复前状态，不修改进程全局线程数。Graph将现有deadline/cancel检查作为同步checkpoint传入，每块/输入扫描/歧义回放中响应；canonical全根回放前后检查。系统单次DGEMM、既有批量输入校验及canonical整根回放不能在内部中断；分块路径在每块前后检查，整根回放前后检查，不能据此保证所有路径的最坏响应以单块为界。

scope_work_budget是现有逻辑子图实例预算，不能将物理分块数改成新逻辑节点扣费；原逻辑工作核算保持不变。实际完成的DGEMM次数在既有accelerate_matmul_calls中累计，包括晚拒绝后全根回放前的库调用，复制及workspace同样不隐藏。已有IPC审计字段承载，避免不必要的新公共算子/结果协议。Observe、内部离散消费者和隔离保持canonical路径。
