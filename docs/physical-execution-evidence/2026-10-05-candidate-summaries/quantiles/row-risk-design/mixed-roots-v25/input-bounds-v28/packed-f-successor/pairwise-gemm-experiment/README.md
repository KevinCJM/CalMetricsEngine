# 高量级矩阵分块BLAS原型：正确性小输出已验证，性能未验收

2026-10-06。现有高量级正负混合矩阵被one-shot绝对差分界挡在Accelerate之外，原测量依然保留；不将反例删为非典型。新实验复用DGEMM和Eigen，分块并以binary-carry树合并，只保存有界输出tile；所有C/F输入及输出通过真实stride借用/写回。没有新canonical算子，没有改当前引擎代码或性能阈值。

152项小输出、长K契约检查实际通过：88项采用、64项保守拒绝。含K2048/4096/4097/8192、四种输入布局、两种输出布局、非整tile、8项抵消零回放、56项非有限/负零/极端/预算拒绝和8项严重抵消回放拒绝。独立Decimal.from_float80位参考检查的最大误差约1.452e-8，旧顺序差分最大约1.462e-7；被检查位置不是完整大矩阵，不能宣称所有输入均完成实测。

数学模型是明确的标准RN binary64条件推导，gamma(2b+2+ceil(log2(q)))*K*maxabs(A)*maxabs(B)对准确实数乘积取向外舍入界，仍限制0.000049。Higham论文提供成对求和模型，Apple文档给double DGEMM能力；它们不是Apple每一内部实现的形式化精度或性能证明。真正采用还须完整工程和数值/残差验证。

额外防线已验证：近零/符号回放可能让新误差证书失效；只有旧值与库值之差加新误差界仍在原预算内才发布旧值，否则放弃整个未发布快结果。8项严重抵消构造专门验证拒绝，不为保留旧零符号无条件输出不准确值。输入、旧结果、线程模式与拒绝时未发布文件保持不变；最终tile复制次数按真实字节记录，不伪称零复制。

此实验只有独立原型的正确性，没有普通Scheduler、AST/DAG/Planner/worker/预算的完整贯通，没有中大型完整时间和heap/RSS，未接入项目源码。先等正在进行的V33质量/性能流程终结，再同条件验证此路线能否实质缩小原始慢路径。不得把152项测试写成CME全算子或完整请求性能通过。
