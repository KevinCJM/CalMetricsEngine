# V37：原生库调研、真实入口筛选与布局退化闭合

2026-10-06。实际运行代码保持V35r2，93份数值源及301份接口/测试/工具冻结文件未变。新版本均为隔离目录中的完整AOT引擎，不是实际目录接入；未提交、推送、安装到全局或部署。

[官方资料核对](v37-method-research.md)覆盖Eigen外部BLAS/LAPACK、OpenBLAS ARM64/macOS及BLIS分块/融合方法。已有Accelerate/Eigen仍负责乘法和归并；公开库的其他硬件/精度成绩不作为本机float64采用证明。双方调用线程明确限制实际Accelerate为单线程，不能把加载的NumPy/OpenBLAS当作NJIT乘法后端。

4096 FF私有诊断中，DGEMM约0.639秒、显式归并约0.306秒、结果检查约0.081秒；这三项属于calculate内部，不能再与calculate总额相加。诊断计时器不在实际引擎中，也没有硬件cache计数证明。三个块形状各通过原152相同输入控制和24项新几何控制；最佳私有长K候选2.714→2.324秒仍慢于同批NJIT 1.379秒。

完整引擎候选另外将Eigen输入检查的4096限制对齐原有根准入8192，不放宽公开准入。保留0.000049误差预算、原归并深度、零/负零及NaN/Inf策略、晚拒绝整根回放、工作区上限、C/F输出和两代独立结果。原生检查覆盖4096/4097/8192/8193、padding、全部舍入模式及SIMD尾部；两版相关回归各3360、原生各9/9均通过，新增8个K8192完整Graph用例已计入3360。第二版另通过原152与新24控制。这里没有重复实际源码全量15146、ASan/UBSan、关闭库或Excel重算，不宣称候选已全面验收。

无条件改块形状虽然长K FF请求2.858786→2.189583秒，却使CC→C 0.992202→1.153140秒；该候选拒绝。第二版按输出布局选择，四组CPU1六轮配对完整请求如下（单位秒）：

| CC→C 4096,4096,4096 | 1.010643 | 0.991352 | 0.644418 |

第二版长K FF路径收益约23.4%，但CC→F退化，因此输出布局单独不足以安全选择；第二版也不采用。不能混用不同批次的基线计算收益。

长K FF另完成12个fresh申请堆/RSS观测。申请堆暖峰实际/隔离版/NJIT为1363.240/1363.240/1348.474 MB；RSS绝对及增量分别保留在[完整审核](review.json)和原始JSON。未得到大额内存节约，不以页差宣称优势。堆探针不覆盖Python arena子分配/mmap，采样RSS可能遗漏短峰；测试未计IPC，worker/shared-memory属于资格检查。

共32组192次时间观测和12次fresh峰值均已终结，原始记录、源hash及失败准备步骤保留。一次性AST/DAG定义和wheel/JIT编译不计时；实际输入准备、普通Scheduler绑定/计划复核/图执行/结果返回和两代保留结果计入。私有ABI数据只用于筛选。
