[数学与实现设计](v38-grouped-dgemm-design.md)依据官方DGEMM的alpha/beta接口和Higham/Mary的经典确定性误差界。隔离候选把原来的四/八个分块乘法改成在同一私有块内由Accelerate累加，完成一组后才由Eigen归并。保留原准入、布局、工作区上限、0.000049预算、独立结果所有权和近零回放；不使用概率界或低精度。新增私有前缀检查并保守计算误差，超预算则在同一辅助实现中按原方法重算未发布的块。该推导基于与现有实现相同的经典binary64模型，并非厂商对全部内部指令的证明。
