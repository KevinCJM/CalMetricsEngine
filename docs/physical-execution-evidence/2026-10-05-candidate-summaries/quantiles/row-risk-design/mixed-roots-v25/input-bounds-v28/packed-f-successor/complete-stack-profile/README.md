# 给定权重完整风险链的真实栈采样

2026-10-06。当前、V29、预热NI三进程串行采样3秒/1ms，每个执行6次262144×2520×30 CPU4 C完整普通请求；三者运行与采样均返回0。采样干扰且非成对，计时/footprint不能作正式时间或峰值验收。它覆盖给定权重、乘法及三风险，不覆盖平台随机探索、修复、Pareto或完整前沿。

Release构建后strip -x移除了本地名称。实际安装和原构建模块UUID/9个TEXT段一致；从既有对象重新链接独立未strip文件后，UUID不同，但全部9段地址、大小、字节SHA相同。按完全相同代码地址复原两种C++采样，原始栈、原拒绝工具、修正方法及[逐地址符号依据](symbolization-proof.json)保留，不宣称重链接UUID相同；没有重编译或修改测得的产物。

[顶栈观测](hotspot-observations.json)只统计>=5频次报告，不把递归inclusive重复计数当耗时百分比。两种C++均出现Highway分位选择约1900–2000个顶栈样本、mask结构校验834、扫描/路径约759、掩码求和约731，以及逐元素和SIMD路径。它说明风险链优化需要继续检查数据遍历、选择和重复结构校验，不能只更换GEMM。NI大多数匿名JIT帧未解析，不猜测其函数比例。并行等待计数不算计算热点。

不能直接删结构校验；INVALID_MASK、gather边界、上游错误后独立结构校验及子作用域契约仍必须保留。后续仅在同样数学和错误语义下考虑成熟库SIMD检查或来自已验证内部生产者的范围证明。这里是观察与设计方向，未实现该优化。
