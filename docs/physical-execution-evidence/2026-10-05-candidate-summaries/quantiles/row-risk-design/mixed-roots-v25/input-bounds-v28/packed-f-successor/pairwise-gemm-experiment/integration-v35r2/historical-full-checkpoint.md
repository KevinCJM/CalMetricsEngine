# V35r2：真实引擎分块候选，完整验收仍在进行

2026-10-06。候选已从独立C ABI接入普通Graph根路径，沿用独立浮点根准入，连续C/F、独立输出、预算及既有worker协议；组合中的离散消费者仍保持canonical路径。当前实际项目仍为已验V33，**尚未应用候选代码、尚未取得完整性能或总体达标结论**。

候选普通AOT身份 `b17f2bbea7aa9cf2c018f289c01757b69f5134046006a70ed9bac35cad16158a`，93份数值源/wheel/worker一致。原152 Decimal80控制同输入hash通过；新增84项真实普通/线程/进程inline/shared回归通过；3352项相关回归和native9/9通过，包括DGEMM已写私有结果之后主动中断、BLAS线程状态恢复、canary、再次执行，以及准入拒绝保持工作区。

首次相关测试保留5项旧物理断言失败：4项预期高幅值一定回退，1项逐位相等；只针对独立浮点根以原0.000049预算及Decimal80修订，未降低预算、未改离散/异常回退断言。随后原生发现实际缺陷：分块计划拒绝前提前扩容工作区。V35r2将临时范数预检与成功准入后的工作区扩容分开，修复拒绝状态；两轮失败及两次准备脚本路径/锚点错误均保留，不能称一次全部通过。

[设计](v35r2-design.md)明确临时范数至多2*8192+8 doubles，先释放再增长主工作区；库内部packing由fresh峰值覆盖。单次系统库调用、既有批量输入检查和整根canonical回放仍不可内部中断，不能保证所有路径的最坏取消响应以单块为界。

普通全量15146项已通过，JUnit逐项确认零失败、错误与跳过；SAN/OFF仍在验证，完整性能尚未闭合。性能队列只在同源完整质量完成后启动：真实普通引擎当前/候选/预热NI，45组270计时与180fresh峰值，保留五组高量级/非整块、两组常规4096和三风险链C/F；编译排除、输入准备与两代只读独立结果计入。不得以原型宽块1.09秒替代候选实际请求成绩。
