# V28：借用连续内存的矩阵准入校验

2026-10-06；隔离候选，未构建、未验收、未接入实际项目。前驱为完整质量通过的 V26。实际项目仍为 0216，完整中大型负载对 NJIT 的时间和峰值内存目标保持开放。

## 问题与边界

V26 已复用 Accelerate DGEMM 并直接写用户要求的 C/F 独立结果。完整请求仍慢于强 NJIT；阶段诊断必须先区分输入校验、库调用、模糊零结果的原顺序重算，以及完整请求边界开销。不能因为源码存在标量循环，就把它认定为主要瓶颈。

本候选只优化独立大 MatMul 根的输入准入扫描。保持 AST、DAG、Planner、数学算法、dtype、C/F 结果、独立只读所有权、错误契约、线程预算与算子接口。共享 MatMul 轨迹的风险链不采用这个独立根路径。无数据指针缓存、无跨请求结果缓存。

## 等价性

先借用至多 64 个逻辑元素，寻找同一 A 行或 B 列中的异号非零对。找到该对只证明原分类器会认定 mixed-sign，不证明其余输入有效。没找到、非有限值、库关闭、几何不适用或存在零时，仍运行原完整分类器。

找到该对且舍入模式允许时，必须对两个矩阵的全部逻辑元素做有限性、绝对值范围、最大绝对值和负号检查。使用 Eigen 公共固定 32 元素 Map 与 min/max，不进行求和、不调整数学累加顺序。逻辑范围外的带 NaN 填充不参与读取。借用 C/F 和合法正步长 padded leading dimension，无整矩阵打包、分配、复制、私有线程池或保留输入指针。

只有两个完整扫描都有效，才使用原有 mixed-sign 误差上界；上界外推舍入、负零处理、非有限错误、模糊零的原始顺序重算、BLAS 单线程设置与恢复保持 V26 实现。最大值必须精确一致，不以抽样估计替代。零返回 scalar_required，不能提前当作零矩阵。unavailable/rejected/scalar_required 不修改调用者的统计结果。

## 验证与采用条件

新增 84 个 Python 回归，覆盖 C/F/padded 输入、C/F 输出、范围、晚出现符号、正负零、NaN/Inf、输入不变、两代独立只读结果和实际库调用。原生用强制库开关验证路径，覆盖整块/尾块、四种舍入模式、精确范围边界、无效几何及未参与计算的 padding。边界统计值使用独立标量参考。

构建前审核补齐测试异常捕获和有效边界最大值的独立核对；记录修改前 SHA，不改写已经测试或测量的前驱源码。之后冻结 257 个源文件及构建/验收脚本。正常相关测试 2429、全量 14715、原生 9；ASan/UBSan 相关 2429、原生 9；三库关闭相关 2189、原生 9，均不得用跳过来消除失败。

现有正式 V26 计时和峰值流水线、阶段诊断结束后才构建和运行新候选，避免污染观测。阶段计时只用于归因；最终比较仍是同数据、算法、输出、核数、输入准备、普通 Scheduler 与两代结果的完整请求。保留当前 C++、V26、强 NJIT 的直接 F 路径，保留拒绝范围和小任务观测，分别报告 warmed requested heap 与 fresh RSS 增量。毫秒/KB 不作为门禁；若诊断显示校验占比很低，则调整优化方向，不宣称这个候选解决整体性能。

## V27 失败与 V28 修订

V27 构建身份 8258301b，相关测试 2413 通过、16 失败，全量/SAN/OFF 尚未启动。16 项失败均为新增 NaN/Inf 用例误写必须抛错；同样用例对质量通过的 V26 也全部以相同原因失败。存量 MatMul 测试和实际调用保持 IEEE NaN/Inf 返回，不能为新测试改变旧数学/错误行为。

V28 只修订该测试文件：非有限分类、Inf 符号、健康行、禁用加速库回退、两代独立只读输出和输入不变都进入核对。数值源码与 V27 完全相同；V27 原源码、失败 XML/日志/状态和构建保持冻结。84 项覆盖与验收数量保持，未删用例、未增加跳过。

阶段诊断 96 个观测已完成：4096 输入完整扫描约 0.19 秒，部分 C/F 交叉布局的库调用也偏慢。NumPy OpenBLAS 的直接诊断不是 NJIT 的真实 BLAS 路径：当前 Numba 通过 scipy.linalg.cython_blas 调用，SciPy 模块实际链接 Accelerate。后续完整请求仍以真实预热 NJIT 为参考；不把只观察到的 NumPy OpenBLAS线程池当作 Numba 所用库。
