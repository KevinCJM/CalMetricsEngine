## 设计与范围

macOS15+arm64、Eigen开启、非scalar、N≥32、F兼容stride(1,pitch)且pitch≥N。M-step另要求D≥8且8整除，以strided Map访问八个独立特征；密度要求D≥8和1≤K≤8，沿八个独立观察行计算，尾行沿用原公式。保留每个值的归约顺序、原exp/log、floor、初始化、停止和错误语义，输入不转C、不整块打包。输出和图/worker协议不变。

密度固定512B局部tile按原row/component顺序写出和检查有限性，保持显式out失败前缀。正式对象局部栈帧752B；M-step均值/方差helper为0/16B。没有新增数值堆工作区；这些局部帧不是完整系统调用栈上界，不能声称整体内存零增长。密度实际有NEON算术，M-step为八个独立标量累加器；新helper未发现FMA。

两轮原型772/579次检查通过，所有正负候选保留。采用密度+gather8；packing略快的记录仍保留，但本轮不为附加差距引入重复输入打包。细节见[详细设计](design.md)与[自审核](self-review.md)。
