# 保序Cholesky有界行面板候选

当前生产基线45213584；上一轮GEMM正式接入已完成且无存活测试进程。整体全部算子时间/内存领先NJIT目标仍开放，本轮先做可证伪的候选筛选。

旧Eigen完整LLT/LAPACK不仅增加内存，还在病态样本改变逐项数值与失败；新内存政策不能自动豁免数学差异。旧Eigen行面板按原输出n行距计算，在大2次幂矩阵存在潜在组冲突，且每次k反复读写当前行。新候选只复制R行到padded连续工作区，保留每个元素逐k减法、除法、sqrt顺序；固定2/4步表达式复用Eigen Array/Map，避免每一步都写回完整行。工作区R*(n+padding)double，有界可预算，输入借用，最后写入原独立C结果，输出上三角继续保存既有镜像供后续行使用。

R行的先前列因素均独立，成组计算f0..fK后，普通前缀及当前下三角分别按原乘法方向和顺序更新，不能以部分和替换逐项减法。只更改依赖允许的物理遍历；数值失败在同一输出重放canonical顺序以返回原错误，不捕获资源/边界异常。无私有线程、JIT或Python数值回调。

冻结4个配置：R8/K2、R16/K2、R32/K2、R16/K4，不按案例挑选获胜方案。先与真实安装包的scalar/auto核验完整输出位模式、状态、只读输入、输出边界；包含SPD、近奇异、overflow、非对称、NaN、C/F/负/间隔布局及尾块。胜出前不改生产。随后单核旧/候选/NJIT、独立结果/保留前次结果、分配与RSS分开测量；小KB/ms变化按当前D8，不更改历史失败证据。

尚不保证生产接入；若没有大负载实质收益或数学失败，则保存原始负结果并切换方向。Excel数学没有改动，当前不新增Excel计算或验收声明。

筛选前固定行距为n+17，避免大二次幂行距/不足一cache-line的padding继续集中到相同组。17是显式候选布局常数，不声称检测本机缓存参数。最初n+1版本的65夹具/325调用正确性结果保留为pitch1-*，未据此作性能选择。

第一轮六组计时四配置全部保留：2048阶R16/K4由约520ms到270ms，512收益仅几ms，1024部分大面板反而退化。继续固定第二轮R16/K4、R8/K8、R16/K8、R16/K16，测试1024/2048/4096阶C/F共六项，验证减少面板重复读写是否能得到大额收益。第二轮源码/计时/校验独立保存，不覆盖第一轮。

正式接入设计（筛选结束后冻结）：采用全组六项一致获胜的R16/K8，n>=1024、macOS15+arm64、Eigen开启、自动ISA，其他情况保留原路径。4096阶C/F约4.42/4.65秒降到1.87/1.96秒，仍显著慢于NJIT，不能宣称目标完成。全6配置的失败/较慢结果不删除。

Workspace显式容纳16*(n+17)+128个double，最后128个为因素表；输入布局全部保留，输出沿用现有C连续独立结果。辅助函数只做依赖允许的前缀面板，行尾除法/sqrt统一使用现有canonical回调，不复制一套Cholesky数学。finite/symmetry仍在调度前，仅数值错误触发原行序重放以恢复错误优先级；资源/边界错误直接传播。

shape-only预算与准备、Planner、执行统一；将已有matmul工作区最大值函数推广为matrix工作区，取顺序节点的最大上界，递归作用域和每worker由现有递归预算覆盖。实际显式ISA不分配新panel；未知shape保守以容量作阶数。变阶但最大arena容量不变时清除旧工作区，禁止预算外滞留。成功路径审计输入→面板和面板→输出两次下三角复制。无全矩阵临时量、私有线程或隐式Eigen堆分配。

验证在真实新wheel上完成：原scalar位级对照、病态与错误优先级、布局/尾块/只读/输出所有权、Planner和prepared预算、线程/进程/共享、ASan/UBSan、EigenOFF、完整Python与185fixture、历史Excel已重算快照对照。完整Scheduler独立输出旧/新/NJIT计时，与冷/热分配/RSS分开测量。Excel公式/数学契约不变；本轮不冒充新的Excel重算。
