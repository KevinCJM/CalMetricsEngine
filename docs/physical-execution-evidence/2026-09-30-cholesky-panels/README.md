## 设计与数学边界

采用固定16行、8步Eigen Array/Map融合，工作区 `16*(n+17)+128` 个double，因素表也纳入Workspace。限定macOS15+arm64、Eigen开启、自动ISA、n≥1024；其他情况保留原路径。输入布局/strides原样借用，输出继续独立C连续。每个元素保留原升序k乘法/减法，最终行处理共用原canonical代码。数值失败重放原行序以恢复错误优先级；资源错误不吞掉，无新私有线程或全矩阵临时量。

完整LLT/LAPACK历史候选存在抵消/病态样本数值契约差异，本轮没有以小内存政策为由豁免数学。两轮全部配置（包括更慢的R16/K16）和65组原型夹具结果保留；不逐shape选择最好成绩。细节见[详细设计](design.md)与[自审核](self-review.md)。
