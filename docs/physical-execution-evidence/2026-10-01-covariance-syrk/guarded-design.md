# 分块误差界、局部重放与原生回退设计

本设计延续本目录裸 DSYRK 的实际问题与 D1/D5/D8、X1/X9/X10，不改变 canonical 数学定义或 `rtol=atol=1e-12`。先在独立 ABI 验证，不能将原型等同于正式 Scheduler 能力；各个原先失败负载仍保留。

## 共享与存储

筛选源码直接包含当前 `matrix_backend.cpp`，使用真实 `covariance_c_means`、`gather_means<8>`、`covariance_ordered_sum`、`original_pair`；完整回退调用同一 `prepare/execute`，不经 Python 数学回调。该引用方式仅用于隔离筛选，正式接入时改为有限的内部共享接口，不将源文件包含方案带入生产。

结果独立 C 连续，输入借用正向 C/F/补边描述。默认512×D中心化面板，加均值、块内平方范数、全程平方范数共 `(512+3)×D` doubles。最新自适应筛选对 `T≤2048、256≤D≤2048` 使用 T 行面板，其上限约32MiB另加三个D向量；4096阶仍使用512行，不能把中等阶面板成本记作零。

长序列的尚未发布结果下三角保存误差界/重放标记，DSYRK 对 C/F 均只写 C 结果的上三角，因此两者不覆盖。短序列使用全局界，不需要每块保存界；F输入采用实测更快的列主序库描述，将候选写入C结果的下三角。逐项读取后，把值写入上三角、标记写入对应下三角，最后重放及镜像。失败后将整块未发布结果交给canonical重写，没有第二块 D×D 工作区。

C 的全程平方范数在中心化扫描中沿原观察顺序累加，同时得到原对角元素；F 的对角元素用原 Eigen 归约重算。均值仅本次请求共享，输入变化后全部重算；原型不保留数值缓存。

## 误差模型及适用边界

采用标准 fp64 舍入模型，`u=2^-53`，`γ_q=q*u/(1-q*u)`；数值界按正数算术增加保守余量，不使用概率界或随机数据假设。依据为 [Higham/Mary 的确定性误差模型及 BLAS 归约讨论](https://eprints.maths.manchester.ac.uk/2673/1/paper.pdf)；[Apple DSYRK 接口](https://developer.apple.com/documentation/accelerate/1513238-cblas_dsyrk)规定对称秩 k 更新，但没有承诺我们的误差界。推导以库执行正常精度的经典点积/归约为前提，不能宣称厂商认证或对任意未来 BLAS 算法的形式化证明；不同库/构建/平台须重新核对准入和差分。

输入非有限或源幅值超过1e4、中心化后非零幅值小于 `2^-400` 或超过8时回到 canonical。中心化幅值条件避免中间乘积溢出/次正规数，并筛掉预计大量重放的幅值域；没有截断、填零或用户输入限制。最初筛选只覆盖 `32≤T≤1,000,000`、`8≤D≤4096` 和正向 C/F，其他范围继续原生计算。正式入口还需工作量选择，微任务无需使用库。

令块长度为 b，块内绝对乘积和上界为 `S=sqrt(sum(delta_j^2)*sum(delta_k^2))`，范数本身按确定性归约误差上调。G 是库上一个块的部分和，B 是与原顺序结果之间的界。C 路径按块使用：

```text
eta >= gamma_(b+1)  (实现使用 b+8 及浮点计算余量)
B_next >= (1+eta)*B + 2*eta*(abs(G)+S)
```

一个 eta 控制原逐项乘加（其初值与 G 相差至多 B），另一个控制当前库块更新。F 原四 lane 累加按 `gamma_(ceil(T/4)+8)*S_total` 界定；库部分和界单独按 `E_next >= E + eta*(abs(G)+S)` 累积，再与原归约界相加。较短 `T≤4096` 采用一次全局点积界，避免逐块扫描 D×D：C 为两份全局 γ，F 为原 lane 深度与库全局深度之和。

归一化后把除法舍入加入 E，只有 `E≤atol+rtol*max(0,abs(candidate)-E)` 才保守满足对原值的容差。`abs(candidate)≤E` 时还不能保证零及正负分类，须按原计算顺序重放；不将小值修补为零。重放比例很高时执行完整 canonical，避免局部重算叠加成第二次全矩阵计算。该比例只控制性能分派，不改变有效输入或数学结果。

## 正式接入所需条件

原型需先验证原失败的 scaled/orthogonal 样本、跨块尾部、C/F 与补边、稀疏不确定项、对角位模式、非有限局部健康结果、策略恢复和所有权，并保留成功/回退计数及所有时间/内存控制。正式采用还需内部共享接口、原生审计及 worker 编解码、Planner 的面板和库估算、原生错误/观察器/独立根资格，以及普通/prepared/线程/进程/共享内存验证。

正式准入必须检查误差模型的实际运行前提，包括标准舍入模式；当前隔离原型以默认环境筛选，尚未实施对非标准舍入环境的拒绝，不能据此准入任意运行环境。当前计数只记录实际喂给DSYRK的面板和成功局部重放，未覆盖中途拒绝的中心化写入及完整回退成本；正式审计须补齐尝试、重放、回退和存储生命周期，不能沿用这些筛选计数宣称完整复制审计。

任何预算只能标记为受测估算，不能把实测系统库工作区称为厂商硬上界。Excel 仍按版本化逻辑 DAG 展开；若只在健康独立浮点根做物理改变，观察器继续原逻辑，不为导出保留额外工作区。本阶段没有新 Excel 重算或全量引擎验收。
