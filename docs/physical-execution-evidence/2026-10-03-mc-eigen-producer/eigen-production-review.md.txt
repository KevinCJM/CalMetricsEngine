## 数学、IEEE 与布局

- `cpp/affine_projection.cpp:33` 的 Eigen 分组只沿相互独立的资产轴，8 资产一组，其余资产走同一标量 fold；没有横向归约、因子分组小计或因素顺序交换。
- 两条路径实例化 `affine_contract_detail::ordered_fold`：显式 initial 起始、factor 递增、coefficient-first 的独立乘法后加法。具名 `Accumulator product` 物化后再加；GCC/Clang 目标使用 `-fno-fast-math -ffp-contract=off`，MSVC 使用现有 `/fp:precise`。未加入全局主机 ISA 要求。
- 每个资产最终调用相同 `std::expm1`；零系数和零权重仍参与乘法。NaN/Inf、取消性抵消及 signed-zero 继续由原 IEEE 运算传播。测试精确比较所有非 NaN IEEE 位及状态，NaN 仅比较类别；不声称 NaN payload 保真。
- 周期与贡献仍使用原 `ordered_weighted_sum` 的 weight-first 乘积，按资产递增求和；贡献状态按 time/path 原顺序跨 tile 累加，不合并 tile 小计。
- 输入 offset、factor_stride、系数 factor stride 均为带符号 `ptrdiff_t`。资产 stride 为 1 时直接借用 K；否则读取 `coefficients.at(factor, asset)` 打包，因而负步长和 transpose 保留逻辑顺序。前置边界仍由既有 bindings/owner/geometry 验证承担，未扩大原生裸指针 API 的安全承诺。
- F 结果使用既有 `Output::set` 和逻辑坐标映射，独立结果直接写入其 C/F 布局；新分支没有结果出口强制转换。

## pack 尾区不重叠的证明

设贡献数为 C，第 i 区间 tile 容量为 q_i，资产数为 A。可写 tile/状态区大小：

```text
B_i = q_i * A + 3 * C
R = F * A             (Eigen 候选非空区间；其余为 0)
M = max_i(B_i + R_i)
```

`cpp/affine_projection.cpp:209` 将 reserve 加入 geometry bound，`:419` 在所有区间准入后取最大 M 并一次分配。系数输入仅允许静态 input 或其 transpose（`:321`），且切片只改变 time 维；F/A 及候选非空区间的 R 在同次调用中保持不变。

实际 pack 地址为 `workspace.doubles.data() + M - R`（`:467`），范围 `[M-R, M)`。每个候选区间有 `B_i + R <= M`，所以 tile/total/weight/divisor 的范围 `[0, B_i)` 不会与 pack 相交。最后一个 divisor 位于 `B_i-1`；pack 最后一项位于 `M-1`。短/长区间的展示顺序不影响这个不等式。空区间不执行 producer/pack，不会破坏已存 pack。

R 最大 16,384 double（128 KiB）；用 `F <= 16384/A` 判定，避免先乘后溢出。A17/F4 的 R=68 double=544B。`affine_projection_workspace_bytes` 使用同一 `bind_geometry`，Planner scratch 包含此保守 reserve，即使 K 可直接借用或本构建 Eigen=OFF 也不低估。现有 vector scratch 在容量不等于 M 时释放后重新建立，indices 也释放，不保留更大的旧容量逃逸新计划。

## 空轴、生命周期、失败和 CPU

- F=0：候选 false，ordered fold 不读取 source/K，保留显式 initial，经相同 expm1；不形成空输入 offset。A=0：producer 不执行，周期 fold 返回既有 +0；路径/外轴为空时不 pack。空样本带贡献仍按原 `INSUFFICIENT_SAMPLE`，不造结果。
- `packed_ready` 和 packed descriptor 都是 `execute_affine_projection` 的调用内变量（`:447`）。复用仅限同调用的静态 K，各次 ordinary/prepared 执行都重新读当前内容；故障后不会留下跨调用数值 cache。可变输入允许在调用之间改变内容，仍须遵守原契约，在执行中保持有效且不被并发修改。
- 所有区间 geometry/layout 先检查，再写任一结果；超出硬 tile 几何时返回 false，继续现有通用原生路径。isolate/额外消费者/公开中间值等无法证明的闭包保持退准入。
- `checkpoint` 调用既有 `native::check_deadline`，并检查 cancellation；发生在入口、每区间和每 tile。入口预取消不写结果；算术故障和后续取消可能留下本次未完成存储，异常阻止其作为成功结果交付。下一次调用重新绑定、重建必要 pack 和贡献状态。128 KiB 的有界 pack 不是无限检查点区域。
- 输入、历史独立结果和结果槽不充当 scratch；结果数据不指向 pack/tile。workspace 仍依原调用方独占/锁定，工作结束前由原 Scheduler 保活输入与输出。
- `EIGEN_DONT_PARALLELIZE` 禁止 Eigen 私有并行；本分支没有 BLAS/新线程池或全局线程设置。实际执行仍在 Scheduler 获准的线程/worker。`vector_elements` 计真实 Eigen-array producer lane 数，并不证明每种目标架构使用了何种 SIMD 指令。
- 只在当前执行线程 `fegetround()==FE_TONEAREST` 时选 Eigen，其他舍入模式走原标量路径；实现不更改调用方舍入模式。
