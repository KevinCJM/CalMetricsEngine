# V52：成熟库矩形覆盖筛选与预算反例

日期：2026-10-07。本轮分类 **PROGRESS_NOT_ADOPTED**。实际数值代码仍为V51；下面是隔离完整AOT候选的结果，不能当作当前生产路径或全面性能验收。

## 做了什么

CodeGraph与实际源码定位到独立MatMul根的旧512–8192输出轴门槛。依据现有BLAS输入布局与公开成熟库方法，在2个隔离C++文件中用原Accelerate DGEMM覆盖长/宽/窄矩形：保留同一最低工作量、LP64边界、K<=8192、原误差证明与canonical回放。长轴符号状态有单独有界字节元数据，Eigen max/finite分类复用<=8192只读视图；不复制整输入、改变C/F输出协议或新增算子/依赖。

同时新增148项Graph/布局/预算/数学/所有权/传输测试，并在原native测试中增加LP64拒绝与bounded-view取消控制。实际93份native/build源、169份已验测试及294份其他既存文件在归档前全部保持原hash。

**P2：原紧预算的可选库回退未贯通。** 8193×256 @256×32 的原完整估计18,943,278 bytes可执行；候选完整估计29,044,598 bytes，使用原18,943,278预算直接MemoryError。同一输入、输出、CPU、普通入口，原/新无预算均成功；原始`v52-budget-admission.json`保留四次结果。增加的保守库reserve没有自动选择原canonical后端，不能通过放宽预算或降低保守上界关闭此反例。因此候选暂不接入。
