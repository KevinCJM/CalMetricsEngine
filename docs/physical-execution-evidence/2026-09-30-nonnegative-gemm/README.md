# 非负域 MatMul：BLAS 准入筛选通过，尚未接入计算图

2026-09-30，macOS arm64。本轮复用系统 Accelerate DGEMM，缩小此前混合符号/近零消去样本的数值缺口；生产 C++、AST/DAG、Planner、worker 和 Excel 未因此改变。本地修改未提交或推送。

## 设计、自审核和数值证据

[设计](design.md)与[原生准入包装](guard.cpp)限定正向 C/F leading dimension、32≤K≤4096、有限非负输入，非零值位于 [2^-128,2^128]；负零、非有限、极端指数和不支持的步长在写出前拒绝。实际矩阵所有者、分配范围及独立结果由测试调用方保证，原型指针 ABI 不是公开输入校验接口。扫描按布局连续方向进行并计入时间，没有输入复制。库调用及线程策略保存/核对/恢复由已有[Accelerate ABI](gemm_tiled_probe.cpp)负责；固定单线程，整次调用或256×256输出块始终使用完整K。

非负乘积没有消去，指数域避免乘加溢出/下溢。在常规稳定浮点归约模型下，保守两份归约误差界 `2γ_(2K)/(1-γ_(2K))` 在K=4096约1.82e-12，低于既有2e-12相对口径。这是准入理由，**不能当作对系统 BLAS 任意版本的数值证明**；固定库/工具链还需对抗差分与独立不变量。未来生产采用应限于独立浮点根及私有转置根，内部比较、排序、状态或其他消费者继续使用原路径；直接算子是否采用须另行设计。

[112组输入×两个库配置](screen.json)共224次受支持对照，通过原 `rtol=2e-12, atol=2e-14`，最大观测相对误差6.5844e-16。覆盖CC/CF/FC/FF、尾部、K=4096、均匀随机、稀疏、幂次、全零及上下界尺度；正值比较、零符号、输入哈希和线程策略恢复同时通过。6个特殊值/越界负控制均拒绝，独立结果的哨兵内容未改。没有用这些固定样本证明全域逐位相同或任意阈值判断一致。[源码和构建身份](build-identity.json)记录所测原生包与原型哈希。

## 时间：完整独立输出的直接 ABI 筛选

单计算核，八轮均衡轮换，每个后端首位两次，已预热实际只读NJIT签名，每次分配独立完整结果并保留上一份输出。计入准入扫描、结果分配和库调用；候选还初始化整块输出哨兵。输入准备、数值复核和哈希在计时外。单位ms，各侧样本中位数；不把隔离ABI计时称为普通Scheduler/进程验收。

| M×K×N / 布局 | 当前 C++ | 整次 BLAS | 256输出块 | NJIT |
| --- | ---: | ---: | ---: | ---: |
| 2048³ / CC | 788.605 | 81.317 | 299.350 | 70.668 |
| 2048³ / FF | 741.137 | 90.797 | 333.608 | 79.534 |
| 4096×512×4096 / FF | 747.659 | 90.639 | 287.378 | 84.477 |

整次BLAS相对现有C++约8.2–9.7倍提速，仍比NJIT多约6–11ms；保留真实绝对/相对差，不把这项小幅差异当作否决显著收益的唯一原因，也不称为时间领先NJIT。256输出块明显慢于整次调用，不继续该配置的正式接入。全部样本和原容差检查保留在[原始记录](screen.json)；[复现脚本](screen.py)已将NJIT布局标记改为实际读取NJIT结果，旧记录的标记不作为布局验收依据。

## 内存：六个有效堆进程和六个独立 RSS 进程

输入构造、库加载和NJIT签名编译在epoch外；cold是首次直接数值计算，warm保留两份独立结果。下表为连续 malloc 追踪峰值MiB；准备阶段没有图或Scheduler对象，因此不能推广为完整图成本。

| 形状 | 当前C++ cold/warm | 整次BLAS cold/warm | NJIT cold/warm |
| --- | ---: | ---: | ---: |
| 2048³ FF | 37.001 / 69.001 | 38.000 / 70.000 | 38.001 / 70.001 |
| 4096×512×4096 FF | 129.251 / 257.251 | 131.000 / 259.000 | 131.001 / 259.001 |

库候选相对现有C++多约1.0/1.75MiB；相对NJIT仅少约1KiB，按用户政策这是基本持平，不宣称有显著内存优势。所有有效堆进程的未知释放及表溢出为0。库内部工作区纳入这些实际峰值，但没有可供Planner使用的全域公开上界；正式接入必须另解决受预算准入，不能把实测峰当作任意形状/系统版本的保证。

RSS请求增量，2048 FF为旧/候选/NJIT约42.125/44.031/76.094MiB；宽输出为约258.594/262.031/259.094MiB。每项只有一个独立进程、采样可能遗漏短峰，不能由此证明普遍驻留内存优势。原始各阶段计数和RSS记录以本目录 `memory-*.json` 为准，malloc不覆盖全部映射、栈和Python arena。

初次6个heap子进程遗漏 `DYLD_INSERT_LIBRARIES`，全零统计为**无效测量**，保留在 `invalid-not-injected/`（本机保留，未随此次提交附带）；随后一次脚本缩进错误保留在 `invalid-indentation/`（本机保留，未随此次提交附带）。修复后显式注入探针重跑六项；[内存脚本](memory.py)另断言cold峰至少包含完整结果，防止未生效探针再次被当作零内存。RSS独立运行，无探针注入。有效与无效证据没有混用。
