# 完整图私有 LU 候选自审核

2026-10-04。审核对象为隔离源码 `924fb468`，不是已采用的生产实现。浮点结果采用用户许可；错误、阈值、布局语义和所有权不放宽。初稿 `23db` 的测试与时间记录不充当当前源码证明。

## 数学与原错误行为

1. 原算子和方程不变，没有正则化、显式求逆或伪逆。调用实际 SDK 的 LAPACK 整数 ABI 与受控单线程 DGETRF/DGETRS。
2. 系数及 RHS 全量有限检查，RHS 先于系数；准入检查仅返回 false，原 canonical 求解负责原异常内容。四个真实奇异阈值反例保留在大矩阵回归。
3. DD 只提供独立逆范数/前向误差界，不把不换行的增长定理套到带主元算法。库 IPIV 必须无交换；通过因子相关的逆范数、主元间隔、Schur 扰动和增长归纳，检查原 ordered 路径远离原阈值。对应系数、RHS 消去及回代有限性的充分条件详见 `lu-certificate.md`。
4. 有限结果还须通过原系数分块重建的独立残差界。面板使用当前 canonical add/sub/multiply，未复制另一份 N² 系数；不四舍五入或改 dtype。
5. 只准入没有其他图消费者的独立浮点 solve 根。比较、索引、分类、递推及其他下游行为不消费新浮点尾差。未知或未满足域必须原路径重建与回放。

## 图、依赖与布局

- producer 保留原求值位置及结构检查；没有延迟到 solve 后从而改变其他节点错误顺序。系数是 sole-use、非公开、非借用、非嵌套融合 add/sub/multiply；直接父是当前仍存活的 persistent leaf。
- 运行时再验证系数指针是其自身 arena、容量足够，且与 RHS 的正/负/零 stride bounding span 和当前结果不重叠。原输入、公共系数和旧结果从不成为可写矩阵。
- F 父矩阵仅在全 dense 同布局时按现有逐元素操作物化 F。C 私有矩阵可原地分块换 F；两者保持逻辑 shape/axes。失败时从原父重建 C 系数，再调用唯一 canonical 求解体。
- 混合布局、非连续/反向父、输入或共享/公开系数、作用域、观察、isolate、F 公共结果及非终端 solve 不采用库路径。它们仍是当前支持的契约路径。
- prepared 每次读本次输入，没有跨请求数值缓存；历史独立结果保留。IPC 仅扩展实际审核字段并更新 wire 版本；旧版本仍拒绝。

## 预算、并行与可移植性

- 小工作区为 64N 面板、4NK RHS/乘积/绝对值和 2N 额外项，另有实际 ABI pivot 和 N 行和。证书 5N 临时向量复用面板空间，64N 已覆盖它。
- 当前 N≥1024、K≤64 下，显式工作区和 512N vendor reserve 估计均落在既有 N² canonical 预算内。vendor reserve 是估计，不是经官方 query 证明的内部硬上界，必须用真实 heap/RSS 复验；不能把未知库内存写成零。
- 库线程策略局部设置并恢复，遵守 Scheduler 外层预算；不建立池或改变进程全局线程配置。CPU1 完整任务先验收；多核收益仍需另证。
- OFF/其他平台继续当前实现。未尝试库的 C 数据不重复重建；F 库准入被拒绝时重建保持 canonical 几何。不是保留未调用的历史实现。
