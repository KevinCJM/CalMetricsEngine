## 设计与边界

固定192×128面板，复用Eigen3.4 pack/gebp，保留升序K、独立乘加、输入C/F/补边strides及既有独立C结果。工作区上界 `(320*K+72)*8` 字节；按形状纳入Planner，运行按实际布局准入。顺序节点复用，子作用域/并发实例按原框架预算。工作区增长先释放已死缓冲；K缩小时不因最大数组面积未变而保留旧面板。没有新增公开算子或私有线程。

[详细设计](design.md)和[自审核](self-review.md)记录数学、归属、溢出、库版本/链接边界。输入绑定无复制不代表算法无打包；4096阶实际打包流量约4.42GB，工作区约10MiB。数学/逻辑图/Excel公式及结果语义不变。

## 正确性、纪律与剩余项

- Python 9,017项；原生、ASan/UBSan、Eigen-OFF各9/9；185算子夹具通过。新增38项覆盖四布局、尾部、IEEE、只读/canary、预算、重复执行及容量缩小、线程/进程/共享内存、嵌套iterate、比较与错误隔离。
- 469组、3,056值与已有Microsoft Excel真实重算快照一致；本轮没有新Excel重算，公式及输入格未改。
- 原phase2诊断3/4通过；63点ordinary比值1.018的旧严格门槛失败原样保留，属于微秒级差异，按当前用户政策不独立否决。不改写为4/4通过。
- 对象和链接worker相关函数未发现FMA；安装worker的text字节与审查的链接产物相同。专用traits只来自一个TU，真实数普通Eigen不会选用该true/true特化。Eigen/编译器升级必须复核；本机验收不替代跨平台CI。
- 大矩阵仍慢于NJIT，额外面板内存也没有形成普遍优势；完整跨算子目标继续开放。
