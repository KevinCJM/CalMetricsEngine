两类候选均不接入。它们通过本轮数值筛选，但没有带来大负载时间收益；生产构建仍为 `76059c20…`，没有重新发布或重跑生产全套验收。

候选复用Eigen公开JacobiRotation：第一类延迟并分块更新特征向量，第二类改变私有上三角块布局。每族59组完整输出/错误/停止对照通过；详细范围见[设计](design.md)和[自审核](self-review.md)。

## 内存与决定

第一族增加2N个double的旋转系数；1024阶为16KiB。第二族工作区为 `(nb*(nb+1)/2)*B²` 个double，其中对角padding计入容量但不计为输入复制；1024阶块4/8/16/32分别比原packed增加12/28/60/124KiB。固定Eigen局部块还占用栈；本轮没有完整堆/RSS或栈上界验收，不能称总内存增量只有这些数。

这些小幅工作区增长不是拒绝理由。候选没有明显加速，1024阶反而多出约0.27秒至6.62秒，因此不接入；原始全部样本与CPU时间见[summary.json](summary.json)。生产源码和上一阶段验收不变，不把候选正确性冒称全面验收。

下一步转向协方差→Cholesky链的独占临时矩阵复用；需先解决失败重放、共享消费者和结果所有权。4096阶单份矩阵128MiB只是潜在节约，尚未实现或实测。全部算子时间/内存目标仍开放。
