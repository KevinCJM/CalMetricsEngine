# 特征分解投影直接写独立结果：设计与隔离验证

本轮从构建`6f02e6bb69d2d59a62781c357eda16f9604ae9eee2377af383b3b56b29c2bf6f`出发。先验证完整特征分解的两个投影可否直接作为同一有界Jacobi的写入目标；不增加公开算子，不改变默认值、扫描、停止、错误、符号或排序。

## 依赖、布局与所有权

仅考虑显式请求同一`symmetric_eigh`的`eigenvalues`与`eigenvectors`，且生产者没有其他消费者、记录根或观察者。特征向量为F连续输出，每列对应原记录的一行；特征值为独立连续向量。两个结果来自一次不可分拆的求解，并有各自结果所有者，不能借用输入或前次结果。矩阵来源在任何输出写入前完成对称/非有限校验和工作区初始化。

把记录访问`record[i,0]`和`record[i,j+1]`分别映射到`values[i]`与`vectors[i*N+j]`。同一Eigen公开JacobiRotation仍旋转长度N的两个连续特征向量列；算式和元素顺序不变。符号规范、稳定排序与循环置换分别移动特征值及其整列，利用已经死亡的矩阵工作区暂存，不能拆散配对。失败路径逐位对照原记录的两个字段，不把ABI隔离实验当成图级成功。

先测试原packed矩阵工作区，再测试前轮N+1行距的连续前缀。后者必须如实预算完整N(N+1)工作区；不能靠提前销毁工作区后再复制结果声称降低生产峰值。理论上，直接投影少一个N(N+1)记录：1024阶约8MiB、2048阶约32MiB。补边工作区会增加约半个方阵，因此其净收益小于上述数字。连续结果的二次幂列距可能有缓存代价，必须实测后选择。

## 验证与采用条件

固定夹具的成功结果及失败缓冲均与原静态库逐位比较；输入只读、输入哈希和前后canary另检查。按照一CPU、已预热NJIT、独立结果、交替顺序测完整普通入口，包含结果分配。ABI只用于筛选，不能替代正式Scheduler验收。记录实际库调用与复制字节，工作区在计算及结果交付时持续存活。

若收益成立，正式实现采用唯一Jacobi模板和结果访问器，连接图级消费约束、精确arena、共享几何、Planner、单/线程/进程、audit及所有权；不保留第二套生产数值逻辑。Observe、isolate、子作用域、多消费者、C显式结果等路径维持已有真实实现。错误校验不能跨过独立结构约束，逻辑AST/DAG与Excel公式不变。全回归、原生/ASan、库关闭和安装身份需重新验收，历史Excel快照只证明同公式复核。

按D1–D8及X1–X10执行。少量KB/毫秒变化仅记录，判断以完整中大型请求的实质收益和预算为准；本实验不代表全部算子已领先NJIT。

## 正式接入设计（筛选后执行）

- 只匹配两个typed float64根，分别为同一私有记录的values/vectors，两个消费者紧邻生产者，生产者没有其他消费者，图内无作用域或isolate。根顺序可互换、名称保留。显式C向量矩阵不准入；auto按该已验证物理写入器选择F。观察器/故障入参及不符合形状的平台保持原记录实现。
- `ExecutionMetadata`只保存来源与两个投影的节点编号。它由现有logical program重新finalize，worker无需新传输字段；AST/Typed IR/Excel依赖不变。按输入实际N和共享资格函数决定物理执行、arena省略及workspace预算，不能仅凭结构就省略非准入形状的记录。
- 首次执行仍按原位置prepare生产者及其全部参数，并检查两个投影的独立结构和两个结果槽的shape/dtype/order/capacity。求解成功后一次发布两个独立Value，随后两个投影只使用已完成输出；不存在指向虚构记录的可读指针。非隔离失败仍直接抛出，旧isolate和观察器维持原求值链。
- 唯一数学模板用编译期结果访问器支持原记录、值单输出及直接双输出。直接双输出才使用补边连续前缀；其他形状与调用维持有实际职责的原packed/dense路径，不保留第二份算法。源和所有结果互不覆盖，排序移动值与整列配对。
- 共享scratch几何函数以受检N(N+1)预算补边区和已有N项排序索引。Planner、Scratch、私有核执行使用相同函数；copy审计累计初始三角写入、每次lower/upper搬运及实际排序移动，直接结果字节单独记录。虚拟容量、申请堆峰及RSS分别报告。
- 初始筛选覆盖512/768/1024；正式准入必须补测2048和零/对角/预算耗尽等负路径。完整请求若有实质时间退化则缩窄或拒绝对应准入，不能用KB级节省掩盖。四执行通道、动态参数/形状、重复独立结果、内存预算、OFF及ASan重点回归，再执行全回归和185夹具。同核NJIT不足明确保留。


## 正式实现与验收结论

已把frontier双投影接入唯一生产Jacobi模板。与基线比较，只改5个生产文件：`cpp/operators/matrix_foundation.cpp`、`cpp/include/calmetrics_engine/operators.hpp`、`cpp/include/calmetrics_engine/graph.hpp`、`cpp/graph.cpp`和`cpp/result_layout.cpp`；另改原生canary测试并新增72项Python回归。直接算子记录格式、185项目录、AST/Typed IR、Excel公式及IPC18不变。实际build为 `52875475af91c979a7b6c6a18dd9d00f298b0e044a0b3e3510d42aeed3601d46`，源77文件、wheel、安装extension和worker身份相符。

正式资格为macOS≥15 arm64、Eigen开启、N≥512且为256倍数；记录只有两个相邻根消费者，无scope/isolate/observer，矩阵输出auto或F。根名和顺序保留。auto对该结构选F，包括不符合尺寸资格的窗口；不合尺寸仍实际生成原记录并物化相同F结果。几何与有效值分开校验，每次重读输入，无数值缓存或新的全局线程池。两个真实独立根写完才发布，后续投影跳过；不可读的geometry校验不暴露虚构记录指针。

原packed记录仍承担非准入路径，未复制第二套生产数学实现。直接路径用N(N+1)补边矩阵、已有N个排序索引及死亡matrix排序带；复制审计包括初始三角、每轮mirror/restore和实际排序移动。2048正常请求算法累计copy为402604080 B，原packed记录为16785408 B；这些是搬运，不包括旋转本身的正常写入，不能称为零拷贝。新增Eigen调用直接借用前缀和F列，无库内全矩阵打包。
