# 独立高斯分量保序计算：正式接入设计与验收

接入前基线为 `52875475af91c979a7b6c6a18dd9d00f298b0e044a0b3e3510d42aeed3601d46`。完整筛选见[独立ABI证据](../2026-10-01-density-states/README.md)：714次成功/失败缓冲逐位对照，较大GMM/HMM完整原生调用分别少约0.250/0.246秒；候选申请堆多8字节，RSS基本持平。该成绩只支持接入候选，不代替下面的正式验收。

## 数学、图与准入

唯一 `density` 内核保持原常数、按特征正序的log方差与平方距离归约、方差下限、逐输出有限检查。用已固定版本的Eigen Array/Map沿4或8个独立高斯分量并行减、乘、真实除法；每个分量的运算次序不变。禁止FMA、倒数替换、向量exp和跨特征重排。逐分量写回并立即检查，异常时保留原公开写前缀。EM初始化、每轮状态更新、概率下限、停止等号及收敛布尔值均不变。

只在已测macOS15+ arm64、Eigen开启、非显式scalar、N≥4096、D≥32、K为4的正倍数、样本特征stride为1时选新路径；K为8的倍数选8，否则选4。样本行及模型行/列按真实stride借用，负步长、补边、只读及广播由原入参边界校验保护。资格按每次实际几何判断，不缓存地址或数值。原F列内核和其准入、小样本、非准入形状、库关闭及其他平台继续承担实际计算职责。

这是物理计算选择，不增加公开算子、版本或数值缓存。AST/DAG依赖、节点执行顺序、CSE、选择根、作用域及Excel数学步骤/预算不变；独立分量没有交叉依赖，可以在现有直接算子、内部节点、EM每轮及子图复用同一内核。已有输出记录/矩阵仍由原所有权链管理，不借用输入或前次结果。

## 缓冲、调度与审计

固定4/8分量Eigen向量只占有界栈，不创建全矩阵、packing或新增数值Workspace；现有密度log缓存和EM Workspace几何保持不变，Planner继续原保守预算。函数独立noinline，避免让所有latent算子的栈帧膨胀。编译保持 `-fno-fast-math -ffp-contract=off`，Eigen不创建线程池、不调用多线程BLAS；计算使用当前Scheduler已有CPU token，不新增进程或全局线程设置。

新增 `eigen_density_calls` 记录一个已完成的Eigen密度调用：状态分量路径和既有F列路径各一次，EM每轮分别计数；不把它解释为SIMD指令数或全算子调用数。direct audit、Scratch聚合/重置、子作用域、native_chunks和worker传输必须贯通；失败算子的聚合沿既有审计规则。IPC从18提升到19，避免旧worker错误解读新增字段；extension/worker与源码身份均重新验证。结果字节、算法复制及工作区审计不因新增计数器改变。
