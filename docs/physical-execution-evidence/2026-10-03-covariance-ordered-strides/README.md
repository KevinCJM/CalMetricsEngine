## 实现与数学复核

仅改matrix_backend.cpp：同一套4×4 Eigen Array有序特征块、128行扫描、尾部/底部四列/最后均值槽增加编译期特征stride。C固定1保留；负F用动态InnerStride，准入T≥32、D≥8、时间stride=−1、特征stride≥T。原始source读取和索引项都为有符号；每格按原逻辑时间逐项累加，正F归约树不变。没有新算子、手写第二数学内核、库、线程或数值workspace；输入和旧结果只读，复用本次结果尾行暂存均值，尾部完整后再归一化/镜像。

直接调用、内部/作用域以及守卫失败后的唯一canonical实现均可受益；守卫资格和容差没有变化。原scalar和库关闭仍可逐位对照。新增60项Python参数案例，扩展原生负F scalar/auto字节对照和source/output canary。汇编确认fmul.2d/fadd.2d，属于静态SIMD证据，不能当执行次数。

## 必须保留的 NJIT 一致性失败

最初source-reject用随机输入乘16384，协方差206/1048576格超出原容差，最大绝对差1.1920928955078125e-7；这是旧C++与NI本来就有的差异，新旧C++逐位一致。相关矩阵最大差4.44e-16、无不合格格。首轮计时在资格检查处退出，原脚本/异常、已完成5例和独立复核[njit-mismatch.json](njit-mismatch.json)全部保留，**没有放宽容差，也没有该失败例的等价NI性能结论**。

后续新增并明确改名为offset_source1024，以加16384验证相同source guard拒绝分支、保持普通协方差尺度。该新案例不能替代或关闭原乘法放大案例的失败。12例计时成功只覆盖最终明确列出的案例。
