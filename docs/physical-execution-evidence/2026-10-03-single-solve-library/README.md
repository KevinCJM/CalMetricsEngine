# 单右端 solve 复用 Eigen：2026-10-03 局部采用

单右端 `solve(A,b)` 复用已经用于 `solve_multi` 的 Eigen Array/Map 保序消元内核，4096 阶完整请求从约 5.90–6.26 秒降至 2.30–2.69 秒。申请峰值未增加，但仍显著慢于 warmed NJIT；**全算子中大型时间与内存领先目标未完成**。仅本地修改，未提交或推送。

旧构建 `5d658a12626a65ea524e82d680c17c04b792bc3e1067f194e18cae2a2704ed8f`，新构建 `2e75f2eabe97084aa63ff03be5351437007dab62dc6d855946460d1f24d16666`。77 项 native 输入中仅 matrix.cpp 和 solve_multi_library.hpp 改变；见[基线](baseline.json)、[最终身份](final-identity.json)、[原生输入差异](native-input-changes.json)、[本轮精确增量](implementation.patch)。共享工作区的其余存量差异不属于本轮增量。

## 设计与数学边界

[开发前设计](DESIGN.md)。沿用 macOS 15+ arm64、Eigen 开启、n≥128、非 scalar 的原准入；小矩阵、显式 scalar、库关闭及其他平台保持原路径。没有新依赖、公开算子、状态、线程池或进程传输字段。

共享消元仍按 32 列面板、固定 16 列两次更新及大矩阵 4 行×8 列更新执行，使用已有 Eigen Array/Map。逐系数的主元顺序和分开的乘减舍入不变，不跳过零因子。面板内已保存的下三角因子随主元换行；仅私有 updater 消费它们，原回代只读取上三角。未用数学行为不同的整套 LAPACK 求解器替换历史契约。

单右端的 `n²+n` 系数/RHS 私有工作区、复制顺序、回代和公开输出写入顺序不变。只给共享内核增加一个编译期主元判据：single 继续仅拒绝 `abs(pivot)<=1e-14`，允许 NaN 传播；multi 默认继续要求 `abs(pivot)>1e-14`，保留原有限性检查和失败前缀。single 消元失败时仍未写公开 out。AST/DAG/Planner、预算、结果布局/所有权与 Excel 公式不变。

先前单右端因小额栈增量未采用；本轮按用户的新验收口径重新评估。几 KB、几 ms 的变化不是独立否决条件；本次没有新增数值堆工作区。编译器实际调用栈未重新定量测量，不能从固定数组逻辑容量推断栈峰值不变。

## 完整请求时间

实际安装的旧/新 wheel，普通 Scheduler、CPU budget=1；每组 9 轮轮换先执行后端，n<256 每轮5次，其余1次。两次初始化运行在计时外，完整请求包含公开结果物化，保留上一份独立结果至下一次返回。NJIT 使用 `np.linalg.solve`，按实际 readonly/layout 签名编译并预热、同一 CPU/BLAS 线程，结果同为独立只读连续向量；控制组返回同形矩阵。单位 ms：[原始全部样本/身份/审计](timing/timing.json)。

## 申请堆与 RSS

2048 C、4096 F 两组，三个后端各自独立 heap/RSS 进程，共12个fresh子进程，[原始记录](memory/memory.json)。输入生成临时块≤64KiB，F/负步长输入按行哈希，避免测量前释放完整矩阵临时而掩盖 RSS。NI 只编译实际签名，不在内存epoch之前执行数值求解。setup/cold/首结果释放/warmup/warm连续追踪；warm保留前次结果，阶段峰值不能相加。

| 阶数/布局 | 旧 cold / warm MiB | 新 cold / warm MiB | NJIT cold / warm MiB |
| --- | ---: | ---: | ---: |
| 2048 C | 32.040991 / 32.057182 | 32.040991 / 32.057182 | 32.571144 / 32.586906 |
| 4096 F | 128.072241 / 128.104057 | 128.072241 / 128.104057 | 129.094582 / 129.125969 |

申请峰新旧完全相等，未新增完整矩阵缓冲；相对 NI 的小额堆优势来自原工作区设计，不是本轮新增节约。RSS请求增量：2048 **32.640625→32.796875 MiB**，NI32.625000；4096 **128.765625→128.703125 MiB**，NI128.656250。新旧分别+160/−64KiB，不写成零，也不据此否决大额时间收益。相对NI仍有176/48KiB正差，不宣称所有内存维度领先。

36个heap阶段无追踪表溢出。**四个原生heap进程在warm峰值采集后的最后结果释放阶段各出现2次untracked free**，旧/新均有，来源尚未定位。冷暖峰值采集阶段该计数均为0；保留原始计数，仅报告所测申请峰，不能声称完整生命周期分配审计通过。RSS每组每后端一个fresh采样，idle control均为0；malloc探针不覆盖全部Python arena内部分配、mmap、线程栈或整个进程树。
