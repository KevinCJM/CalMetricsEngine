# 负向 F 协方差与相关矩阵库路径（2026-10-03）

阶段采用负向F大矩阵加速，**不是全算子性能验收通过**。本轮两项生产文件复用现有Eigen/Accelerate、中心化面板及原数值证书。未提交或推送。

## 实现与审核

时间stride=−1、特征stride≥T的输入原来走scalar有序均值/产品；现在复用C方向的顺序均值、精确对角及单元重放，通过Eigen strided Map直接写既有连续面板，随后DSYRK。负向F不套用正向F的不同归约树。为改善局部性，按8个特征小块遍历均值和面板，每个特征仍按逻辑时间递增累加；C仍整行，正F仍原树。

没有新增整块输入副本、数学实现、线程、依赖或结果契约。源扫描沿物理列、所有地址偏移项为ptrdiff_t，有界形状和leading限制保持索引安全。原1e-12、精确对角、正负/零分类、失败/稠密重放、内部消费者排除、Planner预算及独立C/F所有权不变。

既有IPC将负F打包为正F，worker按其实际布局执行。初次18项测试误用本地负F精确对角，按源码事实修正预期并保留原完整矩阵容差；原失败见initial/focused-initial.log。无需改变IPC或放宽精度。

见[详细设计](DESIGN.md)、[原始至最终差异](implementation.patch)、[自审核](review.json)和[复现命令](commands.md)。77个身份输入仅两个生产文件变化。
