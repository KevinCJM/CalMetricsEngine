# 协方差→Cholesky 复用：正式本机验收（2026-09-30）

当前开发工作树的正式 C++ 已消除单消费者图的一份 D×D 协方差中间矩阵；继续复用既有成熟原生核。4096 阶完整请求冷峰申请堆少128MiB，12组新旧全部输出逐位一致。大矩阵时间变化较小；与 NJIT 相比仍慢约4–5倍，因此全部算子性能目标尚未完成。本轮未提交或推送。
