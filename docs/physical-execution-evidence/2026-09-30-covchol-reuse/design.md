# 协方差→Cholesky 独占缓冲复用设计与边界

本轮先用隔离 ABI 原型验证 Cholesky 原地分解和数值失败恢复，再接入正式图执行。原型设计及其源文件、首次构建错误、54 组完整对照、原始计时与分配样本保留在归档中；隔离 ABI 结果不冒充 Scheduler 验收。正式代码改动由归档 stage-code.patch 给出，四个既有源码的前态逐文件还原后均与任务起点 SHA 相符。

## 数学与依赖

逻辑 AST/DAG 保留 `covariance(X)` 和 `cholesky(A)` 两个节点，数学、轴、dtype、错误码和 Excel 展开不变。仅 typed、raise、非观察执行考虑物理复用；协方差须是单消费者、非公开根并紧邻 Cholesky，源自持久后备。编译期不跨越独立失败节点，不复用仍有共享消费者的存储。isolate、值观察器和受继承故障约束的子图走普通物化路径；普通直接算子仍禁止显式 out 别名。

协方差按现有 C 数值写核直接填充消费方独占 C 缓冲，Cholesky 继续调用现有本机 Eigen 行面板或 portable scalar 核。已处理行只在上三角镜像写入因子；未处理行的下三角不被覆盖；面板先读完整小块再写回。非面板原地路径跳过自复制，保留升序 k 的除法、减法与平方根。数值失败时，只有被原地覆盖的行面板触发内部恢复：重新计算纯协方差，再按原 canonical 顺序重放。前置有限性/对称性、资源与结构错误不吞掉。C 根直接写独立结果，显式 F 根使用现有 C arena 后物化 F。普通、prepared 快照、线程和 worker 的结果所有权边界维持现有协议。

## 分配与计划

消除的中间量是 D²×8 字节：D=2048 为32MiB，D=4096 为128MiB。Eigen Cholesky 面板仍复用已有有界 Workspace；对大矩阵，实际两次下三角搬运审计不变，小矩阵自复制不再计入算法复制。并未修改底层数学核或引入线程、缓存或输入打包。

Planner 当前仍采用保守 arena 上界，覆盖观察器和故障子作用域；因此实际申请堆下降，不表示 plan 的 admission 估计已经下降。后续若收紧估计，必须显式证明每个执行模式都可融合，不能把所有 `plan_array_arena` 调用无条件设为 fuse。根结果及上次独立快照不得被用作临时写缓冲。

## 验收口径

正式安装 wheel 与上一已验收构建、已预热 NJIT 使用相同输入、单核、完整独立矩阵结果；六轮轮换保留前一结果。输入只读，比较全部输出位模式、对 NJIT 的逐项容差、正常/失败路径、实际 arena、冷暖 malloc 与独立 RSS。范围是冻结的12组完整请求及2个大规模内存形状；其余算子全面优于 NJIT 仍未证实。归档中的 native、ASan/UBSan、Eigen-OFF、全量 Python 与历史 Excel 快照提供不同层的证据；历史 Excel 值是实际 Microsoft Excel 重算的既有产物，本轮只复比，并未新重算。
