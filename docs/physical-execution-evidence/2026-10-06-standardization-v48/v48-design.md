# V48：保存短广播输入的二元算术融合

2026-10-06，基于实际 V47 的完整 93 项 native/build 输入；无新增公共算子或 Git 操作。

当前标准化完整链存在约 256 MiB 中间减法实体，时间落后对等 NJIT 约 2.8–2.9 倍。已有广播是借用视图，优化不是重做广播。当前二元物理融合要求第一节点的所有父值持久；mean 的私有 backing 在后续 variance/sqrt 中可能被覆盖，不能无条件放宽。

候选扩展：纯 add/subtract/multiply 的私有单消费者节点，最多一个非持久父值必须为显式 broadcast_like 的短向量。普通非隔离融合上下文、完整已知二维几何、至少两行、向量宽度等于结果列数才准入。其余父值沿既有 persistent 要求。原位置仍调用 canonical prepare，再把该广播的第一行数值复制到原第一节点自身的、直到唯一消费者仍存活的 slot。计划只保留 D 个 double，记录复制字节；其他几何和隔离/观察/上游故障路径保留原执行。

第二节点在原位置准备，执行第一/第二节点既有算术顺序；仅重建被保存的零步长列广播描述符，不访问已失效的向量 backing。metadata 由 finalize 重建，不改变 AST/IR 序列化、公开接口、Planner 协议或 worker 格式。原子原语仍唯一存在，物理优化不是业务组合黑盒。

成熟库：复用项目固定 Eigen 3.4.0。C-order 满足连续行和两条连续列参数广播时，以动态尺寸 Map 的惰性表达式融合整行写入（不构造拥有堆存储的动态 Array）；负步长、其他 dtype/几何沿现有标量路径；F-order 沿已有 Eigen column pair。IEEE 操作顺序和 -ffp-contract=off 不变。除法为短参数分母时先按原条件排除零，遇零不写库结果而进入原标量路径，保留原失败前缀。库关闭仍有原生路径。初版固定 8 值通用 span 对 C 完整请求无实质改善，已移除；r0/r1 wheel 和原始失败/测试/计时保留。新缓存候选不遮蔽原已证明的另一个算术分支；先选择原持久父值融合，再选择需缓存且依赖几何的融合。

数学保持逐值的两次浮点运算与操作数顺序；不复用 variance 的均值、不改 ddof、不改成一遍二阶矩，不跨请求缓存统计结果。短向量来自当前输入和当前逻辑位置，每次重算/保存。源输入只读，公开结果直接写入本次独立所有权存储。

验证：多种运算顺序、C/F/负步长、ddof、空/短/零几何、NaN/Inf/零分母、共享第一节点、后续 slot 复用、重复形状及输入变化；线程/进程/共享内存、prepared/子图与所有权；现有相关回归/native，全量，ASan/UBSan 和禁用 Eigen 的原生回退。完整百万行标准化输入准备、普通入口、同 CPU warm NJIT、两代独立结果轮转配对；新增 fresh malloc/RSS 重复。只有有实质收益及质量通过才采用实际源码，并重建 wheel/worker 和实际复验。不会用本负载替代整个引擎/平台的验收。

Excel：只改变物理存储与执行，同一 logical DAG 及数学原语不变，公式无需改变；核对现有 Excel 运算/广播例子与依赖，普通 C++ 路径不运行 Excel。参考：https://eigen.tuxfamily.org/dox/TopicLazyEvaluation.html ，https://eigen.tuxfamily.org/dox/group__TopicAliasing.html 。


C 完整请求仍慢时核对到 mean/sum 与 variance 的 8 列分组重复读全矩阵：新增成熟 Eigen 有序行归约，仅 C 连续、N≥32、8≤D≤256 且非显式 scalar 的路径；均值/和直接借用目标 D 维累加，方差用两份最大 256 double 的固定栈 Map（最多 4096 字节）保留两遍算法与每列原观察顺序。若列有序和非有限，写输出前回到原八列路径；任何 NaN/Inf 输入必导致对应有序和非有限，有限输入求和溢出也保守回放。平方/结果溢出仍按原列顺序写入/报错。库关闭、F、负步长、更宽矩阵和 scalar 保留现有真实职责的原生路线；不增加 heap scratch 或 Planner 预算，不共享跨节点均值。新增 direct parity 和原 out 失败前缀测试，拓宽完整回归范围到列库及 latent 算子。
