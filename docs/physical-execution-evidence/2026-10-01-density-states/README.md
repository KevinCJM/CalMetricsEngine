## 详细设计与纪律

用成熟Eigen的固定4/8分量Array负责独立减、乘与真实除法，保留每个分量的 `q += (delta*delta)/variance` 运算与特征正序。禁止FMA、倒数变换、归约重排和向量exp。常数/log方差/尺度和结果有限检查仍为原路径；写回逐分量正序，失败结果的可见前缀须与原实现一致。

筛选只使用原生ABI，Python提供固定样本、绑定和测量；ABI调用prepare/execute和独占Workspace。生成的候选来自完整当前 `latent.cpp`，只注入库辅助函数及受限选择分支；用相同实际生产静态库链接其余原生代码。对照使用未经修改的同库。全部候选仅在证据目录与临时目录，不进入生产CMake。

候选选择条件为automatic、macOS15 arm64、N≥32、D≥8、特征步长1、K为分量块的正倍数。F、任意步长、短样本与显式scalar保留原路；样本行可为补边或负步长，模型列/行按真实strides读取。只保留有限有界栈向量，无新全量数组、打包或堆工作区。数值预检及输入只读/所有权不因性能省略。

D1–D8/X1–X10：各分量独立，无随机或跨分量归约依赖；相同输入和模型在每次EM更新后重算，不缓存过期结果；逻辑图、数学公式和Excel预算不变。采用前必须有完整成功/失败缓冲逐位差分、停止阈值邻域、独立NJIT、同核数全负载时间及fresh堆/RSS。ABI定位成绩不是正式Scheduler接入成绩；不假设SIMD必然更快，也不为几KB/几ms孤立收益接入。

生产接口与Excel未变，正式实现、全量回归及Microsoft Excel新重算均未发生。后续结果更新在本页；整体目标保持开放，未提交或推送。

## 完成的筛选结果

714次逐位比较全部通过，另有6次实际基线wheel控制。13组形状、7种样本布局、5种模型布局覆盖4/8分量块、非准入、完整异常缓冲、只读及所有权；EM停止阈值nextafter邻域的整记录、迭代数和收敛值逐位相同。初次build_info键错误及GraphCompiler声明格式错误保留，修正测量脚本后完整复跑，未修改数学或容差。

最终10组计时每组10次均衡轮换，预热/编译在外、一个CPU和完整独立输出；无heap插桩。对照原始NJIT之外，增加每E步只算一次log方差的更快NJIT，10组输入均与原始NJIT整记录array_equal。下表使用较快者，不用重复log的慢基线夸大收益。

12个fresh子进程分别测申请堆和RSS，编译/输入生成在外，完整旧结果保留到新结果返回。GMM原/candidate cold为4214624/4214632 B，warm为4231296/4231304 B；HMM为12604832/12604840及12622016/12622024 B。候选均多8字节，按当前D8不独立否决。更快NJIT的GMM cold/warm为8405808/8422592 B，HMM为16796736/16814144 B，候选各少约4MiB。
