# 同 A 双 solve_multi 根的物理共享

基线为 437269d 构建；只优化同一请求/区间里的两个终端 solve_multi 根，不建立跨请求数值缓存。A 与两 RHS 均为静态 rank-2 输入；两个输出为独立 float64/C 矩阵；两求解节点之间只允许静态输入绑定。scope、isolate、observer、prebound、上游故障、F 输出及额外消费者保持现有执行。

沿用现有 Eigen ordered LU：固定一个或两个 RHS span，A 的面板、主元选择与更新完全不变。每次换行/消元分别对 B1、B2 执行原循环；完整回代 B1 后完整回代 B2。每个 RHS 系数的运算树不变，不能将现有工作区当作标准 LAPACK LU，也不引入 GETRS 或新的求解契约。

使用已有 N² 工作区，各根直接写各自结果槽；只复制一次 A 和各一次 RHS，不拼接 RHS、不额外分配 pivot/矩阵。旧双根已串行复用 N² 工作区，因此本轮不宣称工作区峰值减半。Planner 原有保守预算/工量保留；typed 不走 dag_branch，worker 传输整个 program 后重建资格。

第二节点投机 prepare/资格拒绝不会提前抛错。共享数值失败时恢复第二结果写入区为原初始化零，重新按原节点顺序执行，保留第一根/第二根错误优先级和 caller-owned 输出失败内容；不吞资源异常。两个结果全部成功才登记第二值并跳过第二求解，夹在其中的静态输入节点仍正常绑定。

验收：旧/新成功结果逐位比较；强 NJIT 在计量内合并 RHS 求解一次再拆成独立输出，按原 1e-11 并核对残差/后向误差。覆盖小/中/大矩阵、不同 RHS 宽度、C/F/strides、主元/阈值/非有限/零列、prepared 变更、thread/process/shared 所有权。完整请求计时与 fresh heap/RSS 串行，保留前结果并报告复制审计；KB/ms 差异为诊断，重视实质收益。数值契约未改，Excel 逻辑 DAG/公式不改，适用既有算子/Excel 回归不等于本轮桌面重算。
