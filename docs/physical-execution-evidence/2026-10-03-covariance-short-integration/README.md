## 改动与数学约束

仅修改生产 `cpp/operators/covariance_accelerate.cpp`。承接[隔离筛选](../2026-10-03-covariance-short-panels/README.md)，按实际中心面板幅度选择：C/负F、512≤T≤4096、峰值>8且≤32的协方差/同源双根重试一次128行面板；普通幅度、单相关、正F不改面板选择。晚到极大/极小值或证书不合格仍完整canonical重放。没有新算子、算法契约、输入限制、缓存、线程或IPC字段。

沿用原逐块误差递推、1e-12容差、对角/符号/零和双输出检查，不确定项按原序重放。Eigen Array只改变独立误差单元的物理访问方式：32×32局部转置块将前一部分和连续读取，随后对连续误差行更新；对角块沿原公式。正F长序列使用相同的原递推，未更换归约树或分块大小。推导假设及库适用边界沿用[原设计](../2026-10-01-covariance-syrk/guarded-design.md)，不是对所有厂商算法的形式化认证。

重试先释放原面板再分配；均值和对角随本次输入重算，原先部分库输出在首次短块的 beta=0 与界初始化时覆盖。递归仅允许一次，旧内容不再消费。首次大面板确实分配过，所有中心化写入合计审计；较小最终容量不等于较小请求峰值。固定Eigen数组载荷8 KiB，不是完整调用栈实测值；原Planner保守面板+32MiB库估算不缩减，厂商工作区仍不是硬上界。

数学/依赖/所有权设计见 [design.md](design.md)。原调用链的终端浮点根资格、线程局部BLAS策略恢复、失败路径、独立C/F结果、worker打包及只读输入保留；内部消费者/观察器/isolate排除不变。Excel逻辑与公式未变，普通计算不执行Excel。
