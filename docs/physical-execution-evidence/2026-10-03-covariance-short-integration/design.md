# 条件短面板生产接入设计

基线 ecf16686，2026-10-03；承接 short-panels 隔离证据。仅更改 covariance_accelerate.cpp 内部物理路径，复用现有 Eigen、DSYRK、证书和 canonical 回退，不增加公开算子或后端。

- 只在 C/负 F、512≤T≤4096 的协方差（含 cov+corr 双根）实际中心面板幅度超过8且不超过32时重试128行；单相关、正F及普通幅度保持现有策略。源上限仍为1e4；32是筛选超高幅度的性能选择，不是新输入限制。
- 重试最多一次；原面板先释放，再建立新面板和D向量，重新计算均值和准确对角。每个元素保持原时间序。原面板成本仍计入 materialization_bytes；原保守Planner reserve不缩小。不能把128行最终容量宣传为首次大面板从未分配。
- 重试使用已存在逐块递推，保留原1e-12、精确对角/符号/零、相关消费者检查及不确定单元重放；任何拒绝继续同一canonical。长序列复用等价的Eigen误差扫描，不改变其面板大小。
- Eigen只向量化互不依赖的误差单元，采用固定32×32局部转置块（载荷8 KiB，不作为否决理由），对角块沿原公式。没有新D×D临时量，不修改shared/worker/输出所有权协议，也没有线程池或数值缓存。
- D1/D2/D5/D6/D8：输入改变全部重算，保留输入和旧结果；仅终端浮点根适用，内部/离散/观察/隔离路径仍按现有资格排除。数值和资源硬契约不放宽。X1/X9/X10：Excel逻辑/公式不变，不在普通请求中调用Excel；使用历史快照与本轮参考复核，不能称新Excel重算。
- 验收：原guard/worker/paired/library专项；新增幅度边界、尾块/补边/倒序、prepared在普通→短块→拒绝→恢复之间切换、晚到拒绝、严格预算与独立结果；普通Scheduler完整旧/新/NJIT同CPU配对；独立进程heap/RSS；Python全量、原生、ASan/UBSan、库OFF；77输入及wheel/worker身份核对。保留现有不合格NJIT幅度样本，不以另一个通过样本关闭原失败。

本设计不承诺全算子目标已完成。普通路径回退成本和中大型仍慢于NJIT的项目分别报告；几KB/几毫秒变化只作诊断。
