# 成熟LU与布局筛选：有潜力，尚未进入生产

2026-10-04，正式生产数值源码仍为b43；本阶段只修改隔离实验，不代表总体目标达成，未提交或推送。

同数据、8 RHS、CPU1、预热NJIT、六轮轮转，包含owned readonly输入准备、系数计算、库实际调用和独立C输出：4096阶C/F原型 **0.487/0.414秒**，NJIT **0.733/0.610秒**；同轮正式C++引擎 **2.535/2.621秒**。F系数直接按库布局产生，C使用一份缓冲原地转换，沒有新增N²布局副本。首轮F原型未领先的结果保留。原型浮点容差与独立残差、输入只读和旧结果保留通过。

原型缺少AST/DAG/Planner/worker，因此以上是筛选证据，不能当作正式引擎提速。8个串行内存任务结束：warm requested heap原型/NJIT **689.269/809.539 MB**，少约114.7MiB；fresh RSS增量中位 **693.453/813.023 MB**，绝对峰中位 **836.927/956.793 MB**。原型申请峰比当前b43正式链多约17.1MB，库内部成本不可遗漏；heap/RSS采样与allocator盲区保留。

已找到4个实际阈值状态反例：浮点重排使原算子与库在1e-14附近的通过/拒绝不同。直接换库会破坏契约，即使再检查库U对角也不够。需实现可证明的数值域准入、独立浮点根与存活leaf证明、canonical重建和回放，并复验全部实际路径。
