## 为什么可以扩大范围

相关系数按标准差乘积归一化，继承协方差的绝对源幅度1e4上限会让高幅值输入提前回退，并不是归一化误差证书失败。[设计与范围推导](DESIGN.md)使用原行数上限1e6和非零中心值下界2^-400：新的源上界为平方和、范数积、分母及误差计算保留足够的binary64指数余量。均值、对角、局部重放、密集不确定性回退及最后归一化全部保持原代码。

这只是私有派发范围，超界输入继续按canonical计算；没有归一化输入、截断结果或修改公式。原标准舍入、正向C/F布局、独立单根、CPU/内存预算和所有权条件不变。零方差/非有限分母照旧报错；prepared重读输入并可在错误后恢复。既有BLAS误差模型仍仅对应已测后端，不作所有厂商的形式化保证。
