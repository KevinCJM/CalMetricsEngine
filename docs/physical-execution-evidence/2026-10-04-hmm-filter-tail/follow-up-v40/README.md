[设计](v40-design.md)仅调整已有HMM训练的物理beta存储：无可用loan时保留两个N*K矩阵，加128行checkpoint恢复区；保留完整原后向数值检查、每个xi单元的时间升序和原libm、M步/floor/停止/结果。Planner、直接入口和执行共用checked工作区规则；loan仍借用三个完整矩阵，small单独计算，避免从compact预算减3*N*K下溢。修正版另限制N>=1024，确保compact beta少于原N*K矩阵。公开逻辑算子、AST/DAG、输出和Excel数学契约未改。

当前平台75%训练、random init、K12、D4、上限5轮的模型训练图，从选样、标准化、初始化、GMM预训练到HMM完整拟合，公开八个投影/诊断。使用与13输出图相同的既有数学前缀，删去不被模型结果消费的推断/排序/回填；该训练负载不能替代完整13输出业务链。NJIT仅扩展现有局部停止条件的返回值，无改变数学、阈值、迭代或跨请求缓存。双方准备同六个独立只读声明输入、CPU1、保留上一代到新结果返回；普通绑定/计划/结果返回计入，fixture/一次性图/JIT或wheel编译/预热排除。采用V39已验证的方差对数缓存参考，仍不是最优NJIT证明。
