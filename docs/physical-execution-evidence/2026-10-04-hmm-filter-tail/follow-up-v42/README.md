## 全量覆盖和原始失败

初次全量 15,113 通过、3 失败、59 跳过，原日志/XML 保留。三项失败仅因 HMM 转移概率旧逐字节断言：12 个停止邻点子情形最大绝对差 1.11e-16；其余模型字段和似然逐字节相同，停止次数/收敛及下游标签精确。依照现行 D8 与用户允许的尾差，仅在实际有 vForce 调用时对转移切片采用 absolute 16*epsilon，仍检查 finite/sign；其余字段及未使用库的路径保留 bits，另加精确分类。未改停止规则、数学定义、输入或删用例。

59 个跳过源于初次驱动遗漏 CALMETRICS_TEST_EXPECT_EIGEN/ACCELERATE，补齐原有显式库验收开关后，原失败/跳过的 62 项全部通过；受影响文件 normal/SAN/OFF 各 89 项通过。只改了该文件一个测试函数，其他原已通过断言的源字节保持不变，原同源 15,175 项唯一覆盖闭合；这不是伪造第二次零失败全量 XML。另有 43 项自包含控制在 normal/SAN/OFF 无跳过通过，SAN/OFF 相关各 651/native 各 9；真实 thread/process inline/shared、isolate、恢复、预算、旧结果保留和四种舍入已验证。具体覆盖、源哈希、每个子进程与失败归因均保留。
