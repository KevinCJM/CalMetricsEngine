# V43：训练峰值降低，完整识别链需要按成本选择路线

2026-10-06；状态 **PROGRESS，隔离实验**。生产数值源保持 V42；本轮没有提交、推送或将候选接入实际源码。候选复用当前 density/Eigen、vForce 及有序数学实现，保留一次 backward，消费 emission 后覆盖为 beta，再按 128 行重放 density。

相关 Python **783 项**、原生 **9/9** 通过；真实 V42 wheel 与候选在 12 组布局/边界/维度及 4 种舍入下的完整模型全部逐位一致。不是候选的全量回归、ASan/UBSan 或库关闭验收。

| 完整请求 | 实际 V42 | 隔离 V43 | 预热 NJIT |
| --- | ---: | ---: | ---: |
| 50 万行训练，8 输出 | 5.0732 s | 5.1556 s | 10.5235 s |
| 50 万行识别，13 输出 | 5.2308 s | 5.3080 s | 10.6490 s |

均为 CPU1、相同自有 readonly 输入准备、两代独立 readonly 结果保留；各六轮交替，共 36 个有效观察。额外 10 万行 / 32 因子 / K8 / 三轮完整训练为 V42 0.3977 s、候选 0.4187 s、NJIT 1.2400 s；该样本不是全布局/全维度性能证明。

| 完整请求 | 指标 | 实际 V42 | 隔离 V43 | 预热 NJIT |
| --- | --- | ---: | ---: | ---: |
| 训练 | 连续 malloc 峰值 | 152.603 MB | 116.615 MB | 176.512 MB |
| 训练 | RSS 增量中位数 | 177.652 MB | 137.003 MB | 176.767 MB |

| 识别 | RSS 增量中位数 | 276.267 MB | 276.201 MB | 345.539 MB |

每条请求 12 个新进程观察：各后端一组连续 malloc epoch、三组 RSS。训练 malloc 峰值实测减少 **35,987,712 B**；RSS 中位数减少 **40,648,704 B**。完整识别 malloc 增加 **12,288 B**，RSS 差在页级波动内；**没有新的大额内存收益**。识别旧图已经借用三块空间，无条件重算 density 没有消除实际大矩阵。

上述小幅耗时增加与 KB 变化只作诊断，不构成独立门禁。暂不采用无条件版本，是为了按实际借用成本选择物理路线：已经能无额外分配取得第三矩阵时保留原完整 history；实际能少分配大矩阵时才用重放。须补完复制/寿命审计、全量与 sanitizer/库关闭验收，再在实际工作树构建复测。大矩阵 FF 和平台完整投资空间/前沿负载仍未闭环，总目标继续。

证据边界：malloc 有 Python arena、部分 allocator/mmap/stack 与进程树盲区；RSS 0.5ms 采样可能漏短峰，不能据此称完整分配审计通过。Excel 数学公式未变，没有新增桌面重算验收。原沙箱共享内存失败、旧 3NK 预算断言失败和残留 V35 性能前置条件失败全部保留；最后一项失败发生在计时前，不算性能观察。
