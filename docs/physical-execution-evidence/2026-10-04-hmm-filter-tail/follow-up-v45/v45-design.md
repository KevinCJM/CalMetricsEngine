# V45：修复 HMM 物理路线切换的 Planner 上界

2026-10-06。生产保持 V42；V44 隔离性能和质量测试通过后，额外审查复现一个 P2，故不接入 V44。

## 问题与证明

实际原语在 N≥4096/K≥3 使用两块历史，小于阈值仍用三块；其 scratch 函数在边界不单调。Planner 的形状是区间/子作用域的上界，不能把最大 N 直接代入并假设覆盖较短 N。K256 的 `[4095,4096]` 预算为18,639,112 B，小区间原语至少需26,217,472 B。新增12个元数据/预算回归在原 V44 上为9失败、3通过，没有执行大 K 拟合。

## 唯一几何的上包络

保留 V44 数学内核、无借用的两块原语计划、免费第三历史、复制审计和结果寿命。共享 header 为物理切换行数提供一个 constexpr；Planner 复用 latent_scratch，取最大形状与阈值前最后一个三历史形状的最大值。两段各自单调，因此上包络覆盖所有较短区间；K 的阈值不会形成向下缺口。

修改仅影响保守估计，不增加实际第三块分配、不扩大直接 Workspace，也不修改图的逻辑形状。局部 arguments 只用于预算，没有修改真实输入、DAG 节点或下游输出几何。递归子作用域和私有 canonical 预算通过同一 scratch_estimate 使用该规则。

正常构建、12项正向边界、原797项相关/原生9，以及全量、ASan/UBSan和库关闭必须重新验证。正式完整请求计时和内存仅在其它重任务结束后执行，实际 checkout 构建及复验仍单独记录。V44的历史性能/质量结果保留，不提升为V45当前验收。数学/Excel公式未变，X10不新增桌面重算结论。大矩阵FF和平台完整链路缺口继续保留。
