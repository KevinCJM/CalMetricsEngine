# V45：按实际缓冲成本选择 HMM history

2026-10-06，状态 **PROGRESS，已接入当前未提交源码**。五个 C++ 文件和六个测试更新；不新增算子、公开 API、数学算法或线程池。大 HMM 原语使用两块 NK history，消费 emission 后覆盖成 beta，再按 128 行重放本轮密度；图能免费借到第三块现有 arena/当前未来结果时保留完整 history。小形状保留现有路线，所有平台/库开关使用统一几何规则。Planner取最大形状与切换点前最后一个三历史形状的上包络，覆盖较短区间和子作用域；只调整估计，不扩大直接原语的实际工作区。
