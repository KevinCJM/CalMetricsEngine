### 执行、数学与所有权

1. 只处理现有完整 pointwise 可准入图。隔离错误、标量根、混合几何、不支持 dtype 或有跨元素依赖的图保持现有通路。所有节点先完成原有几何校验；不删独立结构检查。
2. 按原拓扑顺序识别相邻数组计算：最多两个 add/subtract/multiply，及可选比较/finite_mask。标量参数与常量保持 scalar；不融合两个数组相加、非连续依赖或数值域错误算子。长链由多个短区域组成，不生成指数数量的整公式模板，也不引入 JIT。
3. 区域逐项保持左右操作数、运算顺序、NaN/Inf、负零和乘加两次舍入。中间节点被根或其他区域消费时写其已有目的位置；仅区域内部使用的值保留在寄存器。逻辑图、opcode、输出来源和 Excel 逻辑展开依据不变；Excel 后端仍待实现。
4. 泛用缓存块按原逻辑 slot 分配，通过最后使用位置保证复用安全。只复用独占 scratch，不覆盖输入、其他任务、先前结果或尚有消费者的值。短整图链不再为未使用的 block 描述及重复 root 索引分配存储；直接根的写入计数移到区间级，缓存块只遍历确需复制的输入根/重复根。
5. 结构性元数据归图所有，工作区归当前线程；区域内核指针不进入 worker 协议。根继续写独立结果槽，重复根按原契约复制；进程解码后重建区域，统一 Scheduler/CPU 预算和分块边界不变。
6. Planner 采用与执行相同的 slot 容量计算，并保守包含描述开销；估算不是实测。性能计量包含常驻元数据、准备/TLS、结果与可见 allocator 开销的适用范围，不将缓存转移算作零内存。

## 2026-09-24 前序构建：短链寄存器融合与迭代复用

以下为本轮分段融合之前 `69ae777` 构建的历史记录，最新结果以上一节为准。

本轮继续消除张量、短任务与状态计算的实际开销，未更改公式、停止条件、异常策略或性能阈值。改动均位于 `codex/platform-foundation-m0-m1` 未提交工作树。

- **短链 AOT 寄存器融合**：一个数组输入串联最多两个 add/subtract/multiply，末尾可选一个比较或 finite_mask。保持逻辑 DAG 和公共算子，运行时只绑定系数和布局；不使用 JIT、不收缩乘加。根直接写独占结果，不再分配短链中间数值/mask arena。其余兼容图继续缓存块执行。
- **SIMD 与布局**：NEON 将四个向量的比较结果压成八个 0/1 字节，避免逐元素移入标量寄存器；负步长、零步长和一般步长有对应访问路径。可线性遍历的相邻轴合并为一段，避免逆序内轴的重复寻址；没有输入打包复制。迭代残差在寄存器中归约，保留 NaN/Inf 和舍入边界。
- **安全原地迭代**：初态有限，更新是最多两次有限系数乘法（绝对值不超过 1）或加减零时，才证明有限状态封闭。初态复制到独占结果后原地更新，覆盖前读取旧值计算残差；其他子图仍保留候选状态，数值失败返回最后有限状态。首次执行完整校验，后续仅在同一迭代作用域复用固定描述；每轮预算和逐块取消检查保留，跨请求重新检查系数。Planner 仍保守估算双状态容量。
- **入口及描述分配**：移除逐节点保留的完整 Prepared 对象，按需复用一个小 arity 描述。普通 execute 在同一绑定缓存内复用计划，逐次复核输入、区间/产品内容和 CPU；内存预算、Hard Stop、异步策略变化时重建。显式旧计划和 prepared 几何变化仍报错；结果与审计不缓存。

自审核覆盖操作顺序、特殊浮点数、所有比较方向、空数组、跨缓存块反向/零步长/转置布局、重复根独立性、原地更新的有限性证明、可变参数重新验证、计划重建与显式 stale 计划拒绝。NEON/SSE2/AVX2 共用同一短链定义；修复内部空步骤枚举分派的编译告警。没有删改已有公共算子或引入第二个调度器。

## 2026-09-23 历史：缓存块融合与扫描复用

以下全部为上一构建的设计及测量记录，保留用于追溯；其中“当前”“本轮”均指 2026-09-23 的构建。2026-09-24 的实现与验收以上一节为准。

1. **缓存块融合**：逻辑 AST/DAG、CSE 与算子编号保持不变。编译元数据识别无跨元素依赖、无抛出数值域错误的逐元素图。入口完成 dtype、轴、shape 与广播校验，物理层在缓存块内执行已有 canonical SIMD 内核；中间结果不物化为全长数组。无法证明兼容的图继续使用通用执行器，不省略独立结构校验。
2. **根直接输出**：根算子写调用方已独占的结果槽；下游可以读取同一槽。输入根、借用视图、重复根仍按需要复制，不允许输出与输入或先前独立结果重叠。prepared.run 的借用契约和 run_snapshot 的独立契约保持不变。
3. **迭代**：保留最后有限状态与候选状态的独立存储，不能为了省内存原地破坏失败恢复。候选逐块计算后立即检查有限性并归约残差；不改变更新顺序、停止阈值、预算、取消、错误隔离。失败后继续验证独立结构约束。
4. **张量分块线程**：只拆可证明逐元素独立的输出范围，所有根共同执行每一块，避免重复共享上游。由现有 NativeScheduler 分配 CPU token 和持久线程，不在算子内开池。不同 dtype 使用各自字节偏移，不重叠写入。短任务 single；process 保留粗负载和 Hard Stop 隔离用途。
5. **证据**：区分输入绑定、算法 scratch、状态复制、根复制、IPC、共享初始化和结果所有权；记录实际 SIMD 和缓存块执行。分配统计必须说明覆盖范围，不能用 RSS 增量或容量估计冒充完整分配追踪。固定单核门禁继续保留，并补充相同 CPU 预算的已预热 NJIT 对照；比较双方独立结果，保留原始样本。

验收包括浮点边界、NaN/Inf、空张量、广播、非连续与负步长、混合与重复根、返回结果保活、prepared 重复执行、线程/进程协议与原生 sanitizer。性能测试独占执行，不与构建或回归争用 CPU；任何未达标负载均保留失败，不能放宽阈值。

### 实现范围与自审核

本轮实现位于 `codex/platform-foundation-m0-m1`，基于 `730366aa15fe794e7e8b9deeeceffc221605b599` 的未提交工作树。没有修改平台调用链，也没有提交、推送或创建 PR。

| 顺序 | 已实现 | 明确边界 |
| --- | --- | --- |
| 运算链物理融合 | `pointwise.cpp` 按 2048 元素缓存块执行完整兼容图；共享祖先只算一次；中间数组不再按全长分配；连续部分调用 canonical SIMD | 当前是缓存块融合，不是所有表达式的寄存器融合。只接受同形状 float64 输入、纯逐元素安全运算及数组根；不自动抽取混合图中的任意子区域。scalar、bool/int64 输入、isolate、跨元素依赖等仍走通用执行器 |
| 根直接结果 | typed 根写独立输出槽，后继节点复用根存储；只有根占用 numeric slots 时不再分配冗余 numeric arena | 输入根、借用结果和重复根仍需物化；先验证 dtype、rank、capacity，再允许写入。跨执行独立性不变 |
| 迭代复用/扫描 | 连续初态只读借用；结果槽和一个候选缓冲交替；候选块立即完成有限性/残差 SIMD 扫描；非连续初态、别名及最终状态按需复制 | 任意子图可能溢出或失败，因此仍保留最后有限状态；没有用原地破坏状态换取内存优势。数值停止仍验证独立结构错误 |
| 张量分块并行 | 单行、完整兼容逐元素图、连续同形状输入可沿扁平元素范围拆块；线程复用既有池和 CPU token；每块一起计算全部根 | 不把任意矩阵/递推按 shape 自动拆分；中小任务继续 single；迭代依赖轴未并行。并行能力已验证，不等于每种预算均更快 |
| 分配/复制及 NJIT 对照 | 新增执行复制计数、缓存容量计数、隔离 malloc 探针、1/2/4 CPU 预算 NJIT 对照、强制运输路径诊断；原始样本归档 | 这是现有代表负载的分层审计，尚不是全部模型/进程/平台的完整分配覆盖；下述覆盖缺口仍需补齐 |

SIMD 改动把标量广播和输出指针绑定移出热循环，避免 bool 写入可能别名元数据而阻碍提升；有限性/残差扫描提供 NEON/SSE2/AVX2 与标量尾部。没有启用 fast-math、FMA 重排或 Python 数值回退。本机实际执行的是 arm64/NEON，未宣称 x86 实机验证。

自审核重点：缓存块尾部与负步长、未物化中间节点的独立几何校验、根被下游借用、重复根独立所有权、迭代奇偶轮和失败后的最后有限状态、worker 帧边界、tensor 任务不重叠写入、取消后任务排空，以及图切换时 TLS 容量释放。修复了原生异常根 schema 在直接写入前的 dtype/capacity 校验，并为局部父节点数组增加 arity 检查。worker 协议更新为 7；程序协议仍为 7，不能混用旧 worker。

### 分配和复制审计口径

- `input_copy_bytes`：图数值输入绑定复制；本轮 float64 融合路径为 0，负步长按索引访问，没有为 SIMD 暗中打包。
- `root_copy_bytes` / `state_copy_bytes` / `algorithm_copy_bytes`：分别记录根物化、迭代状态复制和算子已登记的 scratch 复制；子图向外累积。不得把 `direct_output_bytes` 的正常计算写入当作复制。
- `boundary_copy_bytes` / `output_copy_bytes` / `shared_memory_bytes`：运输边界复制、结果复制、映射容量；不是操作系统管道内部或 CPU cache 的流量追踪。
- arena、workspace 和 `pointwise_workspace_capacity_bytes` 是保留容量，不是当前请求 malloc 申请总量；`vector_elements` 仅记录显式 SIMD 的“算子或扫描 × 元素”数，不包含无法核实的编译器自动向量化。
- `heap_probe.cpp` 在独立进程中拦截 malloc/calloc/realloc/free/posix_memalign/aligned_alloc；报告申请字节、存活峰值、次数和表溢出。先测冷请求，再测 11 次热请求；热请求排除了更早保留的分配，冷/热峰值不可相加。注入探针不参与时间测量、不进入 wheel。
- 探针的 4 线程 realloc 冒烟测试：40015 次分配与 40015 次释放，最终存活 0、申请峰值 16472 字节、记录表溢出 0。实际基准的记录表也未溢出。
- **未覆盖**：CPython 已有 arena 内的细粒度分配、mmap/shared 区域的逐次申请、独立 worker 的逐次堆事件，以及所有模型/算子路径。当前以共享映射计数及父子进程 RSS 补充，但不能据此声称已实现跨平台、全进程的完整分配追踪。
