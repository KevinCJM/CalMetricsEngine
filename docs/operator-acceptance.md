## 3. 特征分解的对照差异

固定种子 `20260925`、`A = X Xᵀ + 128 I`，默认 `tolerance=1e-12`：

- 与 NJIT/LAPACK 统一符号后的特征向量最大绝对差 `2.1702e-9`，42/16,384 个元素超过既有 `rtol=atol=1e-9` 比较，三个入口均复现。
- 特征值最大差 `1.2506e-12`，相对 Frobenius 重建残差 `2.2490e-12`，最大正交误差 `3.5749e-14`；最小特征值间隔约 `0.00279845`。
- 实现的停止规则约束缩放后的最大非对角元素，不直接保证每个特征向量元素与 LAPACK 相差小于固定阈值。小间隔会放大特征向量差异，因此此结果不足以认定算法错误，但**当前组件对照验收确实失败**。
- 仅作诊断，显式传入 `tolerance=1e-14` 后特征向量差降为 `1.2872e-11`，对照通过。没有据此修改默认值、放宽比较容差或替换默认参数的失败记录。

后续应明确大矩阵的精度目标与残差/特征子空间验收规则，再决定是否优化默认精度；现有原语的数学契约保持不变。

其他复测：

- 原四组门禁 **4/4**：500、1,000 产品组合原生执行分别为 78.797/107.449 ms、110.291/147.486 ms，约快 1.36/1.34 倍；63/252 点普通 Scheduler 及 prepared 均通过原门槛。通过旧门禁不等于实现了中大型大幅领先。

- SIMD 实际审计确认连续百万元素 add/multiply/finite_mask 和 256 阶 matmul 使用 NEON；非连续逐元素样本走 scalar。auto 名称和候选节点不等于所有算子均使用 SIMD。

## 5. 内存统计修正与覆盖边界

旧情景/矩阵脚本把多个跟踪阶段的保留量和峰值相加，会重复计入已经释放的首次结果。本轮在同一分配 epoch 内记录准备、首次执行、首次结果释放、热态基线、热态峰值和最终保留量；重置峰值时保留活跃分配记录。冷/热峰值已经包含当前常驻工作区，不再累加历史峰值。

新增探针回归验证 4 KiB 工作区 + 8 KiB 结果峰值为 12 KiB，释放首次结果后热态峰值仍为 12 KiB。RSS 监控线程先预热，再记录空闲对照和执行峰值。所有报告标记 `continuous-live-1` / `warm-monitor-control-1`，不能直接把旧口径与本轮数值相减当作内核优化收益。

- malloc 家族记录的是申请字节，未覆盖已缓存的 NumPy 分配、Python arena 子分配、mmap 和其他进程；不能称作全进程完整物理内存。
- 情景/矩阵每个后端使用独立子进程，同一后端内部顺序测多个负载；不是每个负载都全新分配器状态。RSS 零增量、页级噪声和空闲对照都保留，优势未证实不记成零成本。
- 6 个既有直接算子内存场景的复用工作区容量未增长，输入复制审计为零；该检查验证复用，不证明全量算子内存优于 NJIT。
- 185 项回放的快照可能变为连续布局，非连续/负 stride 的正确性由全量回归另测。每算子一个回放样本不代表完整数值域或规模性能覆盖。
- 现有 NJIT 性能对照覆盖所列内核/组合，**尚不是全部 185 个算子逐项的小/中/大规模时间与内存矩阵**。部分基线原语假设已验证索引，C++ 仍执行安全检查；基准如实保留这些入口成本，不能通过去掉 C++ 校验换成绩。
